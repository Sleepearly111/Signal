# Sweep Service

- 状态：`experimental / L1 Builds`
- 用途：按严格递增频点执行非阻塞扫频，保存双通道测量结果。
- 接口：`Init/Start/Service/IsDone/GetResult/Abort/Deinit`

## 边界

- 不依赖 HAL、动态内存、固定引脚或题目全局变量。
- 频率设置、测量启动、轮询和安全停止均由板级 Adapter 回调提供。
- 每点具有稳定等待、测量超时、有限重试；整段具有总超时。
- 无效、饱和或输入值非正的结果不会作为有效传递比保存。
- 输出数组由调用者提供，服务不分配内存。

测试源文件覆盖正常点序、重试、计时器回绕、单点/总超时、I/O 故障、
非法频点、Busy 和 Abort。2026-07-24 已用 Arm GCC 14.3.1 和根 CMake/Ninja
构建静态库，构建退出码为 0；测试断言尚未运行，因此不构成 L2 证据。
