# delay_line 基础测试说明

> 当前仅定义测试方法和预期结果，尚未建立自动化测试程序。
> 模块验证状态保持 L0 Software Draft。

## 通用约定

- 调用者提供 `float` 环形存储，容量至少为“最大延迟点数 + 1”；
- 初始化和复位会把全部历史样本清零；
- 浮点比较使用合理 epsilon；
- 除错误测试外，每个调用均应返回 `DELAY_LINE_OK`。

## 1. delay=0

- 初始化：存储容量 5，延迟 0。
- 输入：`{1, 2, 3, 4}`。
- 预期输出：`{1, 2, 3, 4}`，逐样本与输入一致。
- 追加检查：允许输入与输出使用同一缓冲，结果仍保持不变。

## 2. 固定脉冲输入

- 初始化：存储容量 5，延迟 3。
- 输入：`{1, 0, 0, 0, 0, 0}`。
- 预期输出：`{0, 0, 0, 1, 0, 0}`。
- 将输入拆成多个 `DelayLine_Process()` 调用，结果应与一次整块处理一致，以验证流式历史连续性。

## 3. 正弦输入与相位变化

- 生成频率为 `f`、采样率为 `fs` 的正弦输入，并设置延迟 `D` 个样本。
- 稳态预期相位变化：`-360° × f × D / fs`。
- 忽略初始化产生的前 `D` 个零样本后，对比输出与输入的移位关系。
- 例：每周期 8 点、延迟 2 点时，相位滞后 90°。

## 4. 超过最大延迟范围

- 初始化存储容量 5，因此最大延迟为 4 点。
- `DelayLine_Init(..., delay_samples=5)` 应返回 `DELAY_LINE_ERROR_RANGE`。
- 成功初始化后，`DelayLine_SetDelay(..., 5)` 也应返回 `DELAY_LINE_ERROR_RANGE`，并保持原延迟不变。

## 基础错误路径

后续自动测试至少应覆盖空对象、空存储、零存储容量、未初始化对象、非零长度时空输入/输出，以及 `Reset` 后历史重新为零。
