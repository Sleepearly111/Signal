# delay_line 接口规划

## 目标边界

实现与具体信号模型无关的流式整数采样延时线。模块通过调用者上下文保存环形缓冲状态，分数延时属于后续独立评审范围。

## 规划输入

- `DelayLine_Init()`：绑定调用者存储并设置初始延迟；存储容量决定最大延迟；
- `DelayLine_Process()`：处理连续输入块并跨调用保留历史；
- `DelayLine_SetDelay()`：不清空历史地修改整数延迟；
- `DelayLine_Reset()`：清零历史并保留存储绑定和当前延迟。

## 规划输出

- 输出与输入样本数相同；
- 初始历史不足部分输出零；
- 返回空指针、存储容量错误、延迟越界或未初始化等明确状态；
- 输入输出允许完全原地重叠。

## 解耦要求

- 不假设 `1 sample = 1 μs`，时间到样本数的换算由调用者完成；
- 不依赖 2024C 的 1000 点周期缓冲或 SM 命名；
- 不使用动态内存、全局状态或硬件接口；
- 环形缓冲只用于保存流式历史，不把输出定义成有限块的周期回绕。

## 本轮不做

- 不实现分数延时插值或 FIR 设计；
- 不建立 CMake 或完整自动测试框架；
- 不把载波相位换算或时间单位换算放入模块；
- 当前状态保持 experimental / L0 Software Draft。
