# frequency_compensation 接口规划

## 目标边界

规划“校准曲线查询—补偿系数计算—执行器余量检查”的业务接口。通用一维插值应复用 Framework 已有模块，不重复实现。

## 规划输入

- 调用者提供的频率节点与实测衰减或补偿数据；
- 节点数量和数据单位；
- 端点外策略：拒绝、钳位或显式外推；
- 目标幅度、链路增益和调制峰值系数；
- 执行器中心值、上下安全边界和量化范围。

## 规划输出

- 插值后的衰减与补偿系数；
- 补偿后的目标幅度或执行器需求；
- 是否越过上限或下限，以及明确的错误状态。

## 解耦要求

- 不内置 30～40 kHz、RC 截止频率或 2024C 理论表；
- 不复制一维线性插值算法；
- 明确拒绝零、负数、NaN/Inf 和不合法节点；
- 上下安全余量分别计算，不假设执行器关于中心对称；
- 标定表必须由调用者管理来源、日期、负载和仪器条件。

## 本轮不做

- 不实现 `.c/.h`；
- 不建立 CMake 或完整测试框架；
- 不录入或宣称任何实测补偿表；
- 不标记为 stable、成熟模块或独立验证完成。
