# dual_signal_generator 基础测试说明

> 当前仅定义测试方法与预期关系，尚未建立自动化测试程序。
> 模块验证状态保持 L0 Software Draft。

## 通用约定

- 使用 PC C 编译器和 `float` 输出缓冲；
- 浮点比较使用合理 epsilon，不要求逐位相等；
- 除被测参数外，默认 `amplitude=1`、`phase_deg=0`、`delay_seconds=0`、`attenuation_db=0`、无调制；
- 每次调用应返回 `DUAL_SIGNAL_GENERATOR_OK`，并只写入 `buffer_size` 个样本。

## 1. 单频正弦

- 配置：`sample_rate_hz=8`、`freq_hz=1`、`buffer_size=8`。
- 预期：一个完整周期，样本近似为 `sin(2πn/8)`；峰值绝对值为 1，均值接近 0。

## 2. AM，ma=0.3

- 配置：载波 100 Hz、调制 10 Hz、`depth=0.3`、采样率 2 kHz，生成至少一个调制周期。
- 预期：输出满足 `(1 + 0.3 sin(2π·10t)) sin(2π·100t)`；包络范围为 0.7～1.3。
- 检查：在载波非零采样点比较输出与公式参考值，避免用单个载波零交叉点判断包络。

## 3. 相位 0° / 90° / 180°

- 使用相同频率、幅度和采样时间分别生成三组缓冲。
- 预期：90° 结果相对 0° 超前四分之一周期；180° 结果与 0° 结果互为相反数。
- 在 `n=0` 时，0° 输出接近 0，90° 输出接近 +1，180° 输出接近 0。

## 4. 延迟的采样移动

- 配置：`sample_rate_hz=8`、`freq_hz=1`，延迟取 `2 / sample_rate_hz = 0.25 s`。
- 分别生成零延迟与延迟缓冲。
- 预期：延迟结果等于稳态正弦向右移动 2 个样本；按周期比较时，`delayed[n] ≈ baseline[(n-2) mod 8]`。
- 说明：当前模块生成稳态延迟信号，不执行起始区间零填充，也不维护历史状态。

## 5. 衰减 0 / 6 / 12 dB

- 使用相同正弦配置分别生成 0、6、12 dB 缓冲。
- 预期峰值比例分别约为 `1.0`、`0.501187`、`0.251189`。
- 比较各组 RMS 或峰值比，不依赖特定采样点恰好命中峰值。

## 基础错误路径

后续自动测试至少应覆盖空指针、零长度、输出容量不足、频率达到 Nyquist、负幅度、负时延、负衰减、非法调制类型以及 AM 深度超出 `[0,1]`。
