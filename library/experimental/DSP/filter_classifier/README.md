# Filter Classifier

- 状态：`experimental / L1 Builds`
- 用途：把按频率递增的幅频响应分为 LP、HP、BP、BS 或 UNKNOWN。
- 输入：频率 Hz、相对增益 dB、显式阈值与边缘平均窗口。

## 判型边界

模块只根据测得响应的低端、高端、内部峰值和内部谷值做保守判型。
边缘和内部对比不足、多个类型同时满足或数据非法时返回 UNKNOWN/错误，
不会强行给出最接近类型。

阈值属于题目/测量系统配置，不固化历史工程参数。输入值应在进入模块前
完成 Vin/Vout、校准补偿和 dB 换算。测试源文件覆盖四种标准响应、平坦歧义
和非法频轴。2026-07-24 已用 Arm GCC 14.3.1 和根 CMake/Ninja 构建静态库，
构建退出码为 0；测试断言尚未运行，因此仍不是 L2。
