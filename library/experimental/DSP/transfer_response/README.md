# Transfer Response

- 状态：`experimental / L1 Builds`
- 用途：把双通道 Vin/Vout 扫频测量转换为紧凑、带质量门的幅频响应。

## 能力

- 检查频率严格递增；
- 拒绝无效、饱和、输入低于噪声门、非有限值和异常高增益点；
- 计算 `gain_linear = Vout / Vin` 与 `20*log10(gain_linear)`；
- 输出峰值、谷值、动态跨度和拒绝点数；
- 在对数频率轴上插值查找相对峰值的电平交点，可用于 -3 dB 截止频率、
  带宽和中心频率估计。

## 边界

- 输入值必须是同一物理量，例如都为 Vpp 或都为真实 RMS；不得混用。
- ADC 交流采样必须先满足 Nyquist；RMS 检波输出则按 DC 测量链验证。
- 模块不执行采样、不决定阈值、不修复串扰，也不拥有 HAL。
- 质量门和最大增益属于当前题目/测量系统配置。
- 使用标准 C 数学函数 `log10f/powf`，新工程必须评估 Flash、耗时与 `libm`。
