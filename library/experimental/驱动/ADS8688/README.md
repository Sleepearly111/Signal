# ADS8688驱动

> 状态：experimental  
> 当前验证等级：L2 Software Tested（仅主机fake-bus测试）

## 用途与来源

本模块来源于2025G的ADS8688使用经验，只保存ADS8688命令、程序寄存器和单次采样的底层数字协议。

调用者通过`ads8688_transfer_fn`注入一次由CS包围的全双工字节事务。每个器件使用独立`ads8688_t`实例，无固定GPIO、HAL依赖、全局采样数组或隐藏锁。

## 功能

- 写入16位命令寄存器；
- 读写和掩码校验程序寄存器；
- 配置自动序列、通道掉电掩码和各通道量程原始配置字；
- 进入AUTO_RST模式或选择手动通道；
- 读取一次16位转换结果；
- 返回参数、总线和寄存器校验错误。

## 限制

- 不包含AUTO扫描循环、MANUAL读取流程、首次样本丢弃、定时、IRQ、互斥或故障恢复状态机；
- 不包含ADC服务、物理通道与板上丝印映射、2025G损坏通道信息或题目逻辑；
- 不包含GPIO、HAL、软件SPI位时序、CONVST和RESET引脚控制；
- `range_config`保留芯片原始寄存器语义，调用者必须依据数据手册选择量程及滤波设置；
- AUTO与MANUAL切换顺序及流水线延迟由上层服务显式管理，不能混用旧样本；
- 当前fake-bus测试不代表真实器件时序、转换精度或硬件模式切换已经验证；
- 新模块不继承2025G硬件等级。

## 总线回调约定

每次回调必须在一次CS有效期间按顺序完成全部字节传输。程序寄存器读取使用3字节事务，返回值取第3字节；样本读取使用4个零字节时钟，转换结果取后两个字节。

## 测试

fake-bus主机测试覆盖命令编码、寄存器读写、掩码校验、自动序列、掉电掩码、通道量程、AUTO_RST、手动通道命令、样本拼接、非法参数、总线错误和错误时输出保持。

2026-07-21使用TDM-GCC 9.2.0、CMake 4.3.4和Ninja 1.13.2完成独立测试构建。源码按C11及`-Wall -Wextra -Werror`编译；测试程序输出`ads8688 tests passed`，CTest结果为1/1通过。配置、编译、测试程序和CTest退出码均为0。

构建目录为`%TEMP%\ads8688-build-20260721-d4`，Signal目录内未生成构建产物。当前L2不包含真实SPI时序、CONVST、流水线样本归属、AUTO/MANUAL切换回归、转换精度或板级故障恢复。
