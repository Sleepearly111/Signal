# AD9833驱动

> 状态：experimental  
> 当前验证等级：L2 Software Tested（仅主机fake-bus测试）

## 用途与来源

本模块来源于2025G的AD9833驱动经验，只保存AD9833数字寄存器协议、频率字换算、相位设置和波形选择能力。

调用者通过`ad9833_write_word_fn`注入一次16位寄存器写操作，因此可在板级选择硬件SPI或软件GPIO。每个器件使用独立`ad9833_t`实例，无全局变量、固定引脚或隐藏通道选择。

## 功能

- 按调用者提供的主时钟计算28位频率字；
- 设置并选择FREQ0/FREQ1；
- 设置并选择PHASE0/PHASE1；
- 选择正弦、三角和方波；
- 设置或清除RESET位；
- 返回参数、范围和总线错误。

## 限制

- 不包含2025G `dds_output.c`、AD603增益策略、双通道同步策略或默认输出幅度；
- 不包含GPIO、SPI、HAL、MCO时钟配置和延时；
- 写回调必须按AD9833要求完成FSYNC包围的MSB优先16位传输；
- 频率限制为`0 <= fout < MCLK/2`，不判断模拟输出链的实际可用带宽；
- 当前测试仅验证控制字和错误传播，不代表真实器件或板级时序已经验证；
- 新模块不继承2025G硬件等级。

## 测试

fake-bus主机测试覆盖FREQ0/FREQ1频率字、PHASE0/PHASE1、寄存器选择、三种波形、复位、非法参数、范围限制和总线错误传播。
