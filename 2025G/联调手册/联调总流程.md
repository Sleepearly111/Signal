# 2025G 联调总流程（主剧本）

> **怎么用**：硬件到位后，三人**照这份剧本从上到下一步步执行**。
> 每步开头标了谁做：**【硬】**硬件手 / **【软】**软件手 / **【测】**测量仿真手。
> 每人手里再各拿一张速查卡（同目录下），知道自己那步具体怎么操作。
>
> **铁律**：全部达标前，任何代码/参数都不抽进模板库。这份只管把 G 题调通。

---

## 信号链（先在脑子里过一遍）

```
AD9833(DDS,~0.6Vpp) → AD603(VGA,增益可调) → AD8052(×5) → [装置输出]
                          ↑                                    │
                       DAC/PA4 控制                            ▼
                                                        已知电路 H(s)
                                                              │
                                                              ▼
                                                        [电路输出]
     ADS8688(16bit ADC): CH0 量【装置输出】(基本2/3/4都测这里)
     ⚠️ 已知电路【电路输出】只接示波器,基础3/4不许接回装置(题目说明2)
```

- **基本(2)** 管【装置输出】≥3V（目标3.5V），量 **CH0**，纯闭环。
- **基本(3)** 定死 1kHz → 让【电路输出】=2V：算需要的装置输出、量 **CH0** 闭环调装置输出，电路输出靠 H(s) 开环、只给示波器看。
- **基本(4)** 可设 100~3kHz + 可设 1~2V(步长0.1V) → 同基本(3)，量 **CH0** 调装置输出，纯前馈，误差≤5% 靠 |H| 实测表保证。

## 阶段 0 — 通电前检查（别急着上电）

| | 步骤 |
|---|---|
| **【硬】** | 照《硬件手速查卡》的接线表接好所有线，**重点**：ADS8688 **CH0 接装置输出**；已知电路的**电路输出只接示波器**（基础3/4 题目禁止接回装置）|
| **【硬】** | 检查供电（各芯片 VCC/GND）、有没有短路、AD603 控制脚接到 **PA4** |
| **【硬】** | 接好后**拍张接线照片**，标清楚 CH0 接哪 → 发群里存档 |
| **【测】** | 准备好仪器：示波器、万用表、（若需要）信号源；确认探头校准 |
| **【软】** | 确认代码能编过、出 `build/Debug/app.elf`（见《软件手速查卡》）|

> ⚠️ **卡点**：CH0 必须接【装置输出】；已知电路输出**只接示波器**，接回装置=违反题目"说明2"(基本3/4无反馈连接)。

## 阶段 1 — 上电 + 烧录 + 基本连通

| | 步骤 | 通过标准 |
|---|---|---|
| **【硬】** | 上电，测各路电压正常 | 无冒烟、电压对 |
| **【软】** | 烧录 `app.elf` | 无报错 |
| **【软】** | 打开调试串口(USART2)，看启动打印 | 出现 `2025G 电路模型探究装置 启动`、`ADS8688 OK` |
| **【软】** | 若打印 `ADS8688 init failed` | → 【硬】查 ADS8688 供电/片选/SPI 接线 |
| **【硬+软】** | 串口屏点一下 / 按 KEY，看有没有反应 | 屏能收到指令、模式能切换 |

## 阶段 2 — 标定 5 个值（最关键，慢慢来）

> 目的：把《软件手速查卡》里 `app_config.h` 的 5 个 `TODO` 换成实测值。
> 顺序有讲究：**先测信号源头，再测放大链**。

| 顺序 | | 步骤 |
|---|---|---|
| ① | **【测】** | 测 **AD9833 裸输出 Vpp**（AD603 之前那个点），记下 → 填 `AD9833_DEFAULT_VPP` |
| ② | **【测】** | 测 **AD8052 放大倍数**（量它输入、输出，相除）→ 填 `AD8052_GAIN` |
| ③ | **【测+软】** | 测 **DAC 满幅电压**：软件手把 DAC 设满(4095)，测量手用万用表量 PA4 → 填 `AD603_DAC_VREF` |
| ④ | **【测+软】** | 测 **AD603 增益曲线**：软件手依次给 Vg=0/0.5/1.0V，测量手记每档输出 Vpp、反算 dB，拟合直线 → 填 `AD603_GAIN_SLOPE`、`AD603_GAIN_OFFSET` |
| ⚠️ | **【测】** | **确认斜率正负号**：电压升→增益升（正斜率）还是电压升→增益降（负斜率）？填对号！（详见测量卡） |
| ⑤ | **【软】** | 5 个值填完，**重新编译烧录** |

> 每填一个值，可以顺手记进《测量仿真手速查卡》后面的数据表，留档写报告用。

## 阶段 3 — 验证基本(2)（装置输出 ≥3V）

| | 步骤 | 通过标准 |
|---|---|---|
| **【软】** | 串口屏发命令 `0x04`+频率，跑基本(2) | LED1 亮灭一次，串口打印 `[CAL]` 过程 |
| **【测】** | 示波器量【装置输出】Vpp | 稳定 ≈3.5V |
| **【软+测】** | **从 100Hz 扫到最高频**（100Hz 一档往上，直到 ≥1MHz），逐点看 | 每个频点都 ≥3V |
| ⚠️ | **【测】** | 特别看**低频(<1kHz)和高频端**：AD9833 这两头会衰减，闭环能不能补到 3.5V？ | 若某频点到不了 → 见下方【兜底】|

> **【兜底】** 若低频或高频闭环到不了 3.5V（撞增益上限 / 高频量不准）：
> → 【测】记下那几个频点、当时能到的最大 Vpp；
> → 【软】按参考代码给基本(2)加"频段开环固定增益"（低频/高频各给一个实测倍数），再测。
> （现在代码是纯闭环，没加这个，够不够等这一步才知道。）

## 阶段 4 — 验证基本(3)（1kHz → 电路输出 2V）

> 合规：装置**不测电路输出**。装置只把自己的输出调到 `2V / |H(1kHz)|`，电路靠 H(s) 开环产生 2V。

| | 步骤 | 通过标准 |
|---|---|---|
| **【测+软】** | 先做**基本(1)**：测出各频点 `|H|` 填进 `transfer_calc.c` 的表、`H_LUT_FILLED` 改 1 重烧（软件卡①） | \|H\|表就绪（≤5%靠它） |
| **【软】** | 串口屏发 `0x01`，跑基本(3) | 打印 `\|H(1kHz)\|=.. → 需装置输出 ..` + `[SET]` 收敛 |
| **【测】** | 示波器量【电路输出】Vpp（**只看，不接回装置**） | ≈2V，误差≤5% |
| **【测】** | 对照《测量卡》参考值（1kHz \|H\|≈2.52、需装置输出≈0.79V） | 数量级对得上 |

> H(s) 已确认 `5/(1e-8·s²+3e-4·s+1)`（1kHz≈2.52）；但公式只保证≤10%，**要≤5% 必须填基本(1)实测 \|H\| 表**。

---

## 阶段 5 — 验证基本(4)（100~3kHz + 1~2V + 误差≤5%）

| | 步骤 | 通过标准 |
|---|---|---|
| **【软】** | 同基本(3)：靠 \|H\| 表 + 装置输出闭环，**不测电路输出**（`H_LUT_FILLED=1`） | — |
| **【软】** | 串口屏发 `0x02`(设频100~3000) + `0x03`(设压10~20，即1.0~2.0V) | 打印 \|H\|、需装置输出、`[SET]`收敛 |
| **【测】** | 示波器量【电路输出】（只看，不接回装置） | =设定值，误差≤5% |
| **【软+测】** | 多试几组：频率(100/500/1000/2000/3000Hz) × 电压(1.0/1.5/2.0V) | 每组误差都≤5% |
| ⚠️ | 若装置输出调不下来（需要值很小、卡在偏高） | → 硬件链增益过高，见软件卡③ |
| | 若某组电路输出误差>5% | → \|H\| 表该频点不够准，重测该点 |

## 联调风险点速查（出问题先看这里）

| 现象 | 先查 | 谁 |
|---|---|---|
| 读不到 ADS8688 | 供电/片选/SPI 接线；`ADS8688 OK` 打印 | 硬 |
| 基本3/4电路输出误差>5% | \|H\|表没填/该点不准；装置输出闭环有没有收敛(`[SET]`) | 测+软 |
| 基本3/4装置输出调不下来 | 硬件链增益太高(AD8052×5+VGA降不够) | 硬+软 |
| 输出幅度差一截 | 5 个标定值，尤其 AD603 斜率**正负号** | 测+软 |
| 基本2 低频/高频到不了3.5V | AD9833 衰减，加频段兜底 | 测+软 |
| 基本4 误差>5% | 标定精度、是否需多次修正 | 软 |
| 串口屏没反应 | 波特率、帧尾0xFF×3、发送串口 | 软 |
| 按键没反应 | EXTI沿、消抖、上下拉 | 硬+软 |
