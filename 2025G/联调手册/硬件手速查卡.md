## 2. ⚠️ 最关键：ADS8688 接哪（题目有硬约束）

**题目"说明2"规定：基本(3)(4)中，探究装置与"已知模型电路"输出端【无任何反馈连接】。**
所以基础三题里，ADS8688 **只测【装置自身输出】，绝不接已知电路的输出端**。

```
CH0  ←接─  【装置输出】(AD8052 之后、进已知电路之前)   → 基本(2)(3)(4) 都量这里
已知电路输出  ──只接─→  示波器(评委看)     ✗ 不许接回装置！
```

- 基本(2)：靠 CH0 闭环把装置输出调到 ≥3.5V。
- 基本(3)(4)：靠 CH0 把装置输出调到"算出来的值"，电路输出由 H(s) 开环产生、**只给示波器看**。
- 接好后**拍照标注 CH0 接哪**，跟软件手确认。

> **CH1 先留空**：留给**发挥(1)**——那时要连"未知电路"的输入和输出做学习建模（学习阶段允许连输出）。基础三题用不到 CH1。

## 3. 通电前检查清单

- [ ] 各芯片 VCC / GND 到位，电压对（AD9833、AD603、AD8052、ADS8688）
- [ ] 无短路（重点电源对地）
- [ ] AD603 控制脚确实接到 **PA4**
- [ ] ADS8688 **CH0=装置输出**，已拍照确认（**电路输出只接示波器，不许接回装置**）
- [ ] 片选 CS、复位 RST 接对
- [ ] 已知电路（H(s) 那个 R/L/C 网络）接在 装置输出 与 电路输出 之间
- [ ] **去耦电容到位**（见下方 3.5，尤其 AD603/VGA，漏了输出会带电源噪声）

## 3.5 ⚡ 去耦 / 电源完整性（VGA 尤其重要）

AD603 是**压控增益**芯片，电源噪声会直接串到增益上、让输出抖，比普通放大器更挑电源。

- [ ] **每个 VCC 脚就近 0.1µF 陶瓷**（贴引脚、走线短）——AD603、AD8052、AD9833、ADS8688 都要
- [ ] 每颗芯片再配一个 **~10µF 钽/电解** 做大容量储能
- [ ] **模拟电源 / 数字电源分开**，单点（星型）接地，别让数字噪声灌进模拟
- [ ] **DAC 控制线（PA4→AD603 Vg）**保持干净，必要时加 RC 低通（Vg 抖 = 增益抖 = 输出抖）
- [ ] 具体容值/布局照 **AD603 数据手册**推荐

> 软件端的 RMS+平均只能压掉一点随机噪声，**根源必须靠去耦**——电源脏了信号本身就脏。

## 4. 你要准备/引出的测量点

给测量仿真手留好探头能夹的点：
- **AD9833 裸输出**（AD603 之前）——测源信号 Vpp
- **AD8052 输入、输出**——测放大倍数
- **PA4（DAC 输出）**——万用表测满幅电压
- **装置输出**（=ADS8688 CH0 点）
- **电路输出**（**只接示波器**，基础三题不接回装置）

## 5. 常见硬件问题

| 现象 | 你查什么 |
|---|---|
| 串口打印 `ADS8688 init failed` | ADS8688 供电、CS 片选、SPI 六根线（PD0~5）接线 |
| 量到的值明显不对 | CH0 是否接对装置输出点、探头是否接对点 |
| 按键没反应 | KEY 上下拉、下降沿、有没有接到 PE3/PE4 |
| AD603 增益调不动 | PA4 到 AD603 控制脚这条线、AD603 供电 |
| 输出带很大直流偏置 | 各级耦合、参考地是否共地 |
