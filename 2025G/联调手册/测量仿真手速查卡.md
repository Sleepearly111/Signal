# 测量仿真手 · 联调速查卡

> 你负责：用仪器测出 5 个标定值报给软件手、记录数据、（备用）导出 H(s) 仿真表。
> 配合《联调总流程》用。

## 1. 仪器 → 测什么

| 仪器 | 用来测 |
|---|---|
| **示波器** | 各点 Vpp（交流幅度）：AD9833输出、AD8052输入/输出、装置输出、电路输出 |
| **万用表** | DAC 满幅电压（PA4 直流）|
| **信号源**（如需）| 单独给某级喂已知信号验证 |

测量点让硬件手提前引出（见硬件卡第4节）。

## 2. ⭐ 5 个标定值怎么测（报数给软件手填 app_config.h）

**顺序：先测源头，再测放大链。**

### ① AD9833_DEFAULT_VPP —— AD9833 裸输出
- 示波器夹 **AD9833 输出**（AD603 之前）。
- 让装置输出 1kHz 正弦，读 **Vpp**。
- 报给软件手（占位 0.6V，实测可能 0.5~0.65）。

### ② AD8052_GAIN —— 运放放大倍数
- 同时量 **AD8052 输入 Vpp** 和 **输出 Vpp**。
- `增益 = 输出Vpp / 输入Vpp`（占位 5.0）。

### ③ AD603_DAC_VREF —— DAC 满幅电压
- 【软件手】把 DAC 设到满幅（4095）。
- 你用**万用表**量 **PA4** 直流电压，读数就是 VREF（占位 3.246V）。

### ④ AD603_GAIN_SLOPE / OFFSET —— AD603 增益直线
这是重头。要拟合一条直线 `增益(dB) = SLOPE×Vg + OFFSET`：

| Vg（软件手设 DAC 给）| AD603 输入 Vpp | AD603 输出 Vpp | 增益倍数=输出/输入 | 增益dB=20·log₁₀(倍数) |
|---|---|---|---|---|
| 0.0 V | | | | |
| 0.5 V | | | | |
| 1.0 V | | | | |

- 【软件手】依次把 Vg 设成 0 / 0.5 / 1.0V（他控制 DAC）。
- 你量每档的 AD603 输入、输出 Vpp，算出增益 dB，填表。
- 拟合直线：
  - `SLOPE = (dB@1.0V − dB@0.0V) / (1.0 − 0.0)`
  - `OFFSET = dB@0.0V`
- 把 SLOPE、OFFSET 报给软件手。

### ⚠️ ④补充：斜率正负号（最容易踩的坑）
- 看你表里：**Vg 从 0 升到 1.0V，增益 dB 是变大还是变小？**
  - 变大 → **SLOPE 为正**（如 +40）
  - 变小 → **SLOPE 为负**（如 −25）—— 参考队就是负的！
- 一定把**符号**跟软件手讲清楚，填错号增益方向全反、闭环会发散。

## 4. ⭐ 基本(1) 实测 |H| 表（基本3/4 达标的关键，必做）

> 题目规定基本(3)(4)**不能测电路输出**，装置只能靠**已知的 |H|** 前馈。
> 而 H(s) 理想公式只保证≤10%，要达到基本(3)(4) 的 **≤5%**，**必须实测 |H| 填表**。
> 这活正好就是**基本(1)** 的测试内容，一并做掉。

- 给已知电路输入端加 **freq、1Vpp 正弦**（信号源或装置都行），示波器量**电路输出 Vpp**。
- `|H(freq)| = 电路输出Vpp / 电路输入Vpp`。
- 频率覆盖 **100Hz~3kHz**，逐点测（点密一些，谐振区~1.6kHz附近更密）。
- 报给软件手填进 [transfer_calc.c](../Src/transfer_calc.c) 的 `g_h_table`，填完 `H_LUT_FILLED` 改 1。

参考（公式值，仅供量级核对，**以实测为准**）：

```
100Hz→4.93  300→4.47  500→3.83  700→3.23  1000→2.52
1300→2.02  1600→1.66  2000→1.31  2500→1.01  3000→0.81
```

> 参考队实测 1kHz |H|=2.5192，与公式 2.52 吻合 → 公式量级可信，但精确值仍以你板实测为准。
> （若来不及逐点实测，也可用仿真 AC 分析导表兜底，但实测最准。）
