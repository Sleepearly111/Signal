# 电路模型探究装置（G 题）· 题目全文

> 来源：`D题_电路模型探究装置.docx` 提取，2025 年全国大学生电子设计竞赛【本科组】。
> 本文件为工程内留档，方便随时核对指标。

## 一、任务

设计并制作 RC 有源滤波电路（简称**已知模型电路**）和电路模型探究装置（简称**探究装置**）。

- **基本要求**中，探究装置可自动调节本身的输出信号并加给"已知模型电路"，使该电路按要求输出信号；
- **发挥部分**中，探究装置可对测评现场提供的"**未知模型电路**"进行自主学习、建模，并根据该电路输入端的信号推理生成与该电路相同的输出信号。

## 二、要求

### 1. 基本要求

**（1）** 在单独的电路板上搭建电压传递函数为 H(s) 的"已知模型电路"。由信号发生器输入频率 **100Hz~3kHz、峰峰值 1V** 的正弦信号，用示波器测量该电路输出电压幅度。要求该电路输出电压幅度与传递函数 H(s) 表征的输出电压幅度**相对误差绝对值 ≤ 10%**。

**（2）** 探究装置能产生正弦信号，频率可设置（**步长 100Hz**），**最高频率 ≥ 1MHz**，**频率相对误差 ≤ 5%**；各频点输出电压**峰峰值最大值 ≥ 3V**。

**（3）** 探究装置输出端接"已知模型电路"输入端。设置探究装置输出 **1kHz** 正弦，依据（1）的 H(s) 确定输出幅度，使"已知模型电路"输出**峰峰值 = 2V**。要求该电路输出与设定值（2V）**相对误差 ≤ 5%**。

**（4）** 探究装置可设置并输出 **100Hz~3kHz** 的正弦信号，依据（1）的 H(s) 确定输出幅度，使"已知模型电路"输出峰峰值为设定值（**范围 1~2V、步长 0.1V**）。要求该电路输出与设定值**相对误差 ≤ 5%**。

### 2. 发挥部分

**（1）** 测评现场提供由 **RLC 元件（各 1 个）** 组成的"未知模型电路"。探究装置连接该电路输入和输出端口，对其**自主学习、建模**（**不可借助外部测试设备**），**2 分钟内**完成学习建模，显示该电路的**滤波类型**（低通/高通/带通/带阻）。

**（2）** 学习建模完成后，**断开**探究装置与"未知模型电路"的连接，将信号发生器接入探究装置和"未知模型电路"的输入端口（探究装置输入电阻 **≥ 100kΩ**）。探究装置根据信号发生器输出信号**推理生成与"未知模型电路"相同的输出信号**。要求两者输出**波形无失真**、示波器上**连续同频稳定显示**（相位无要求），**峰峰值相对误差 ≤ 10%**。
> 信号发生器输出：频率 **1kHz~50kHz（步长 200Hz）、峰峰值 2V** 的周期信号，类型：**正弦波、矩形波（占空比 10%~50%、步长 5%）和其他周期信号**。

**（3）** 其他。

## 三、说明

1. 预留各输入、输出端信号测试端口。
2. **基本要求（3）（4）和发挥部分（2）中，"已知模型电路"和"未知模型电路"的输入、输出端均只有 1 根信号线和地线，探究装置与其输出端【无任何反馈连接】；探究装置需在启动后 5s 内生成信号输出。**  ← ⚠️ 关键约束
3. 基本要求（3）（4）中，探究装置具有通过按键等设置所产生信号的频率、所控制的"已知模型电路"输出电压值功能。**设置完成后一键启动，后续不可人工干预。**
4. 发挥部分（1）中，"未知模型电路"元件值范围：**R 1kΩ~10kΩ，L 1mH~10mH，C 10nF~100nF**；用唯一"**学习键**"启动学习建模，后续不可人工干预；滤波类型指低通/高通/带通/带阻。
5. 发挥部分（2）中，信号发生器设置完成后一键启动，后续不可人工干预。示波器以"未知模型电路"输出为触发通道，要求双踪显示的探究装置与"未知模型电路"输出波形相同、无漂移。

## 关键约束提炼（写代码/接线必记）

1. **基本(3)(4) 无反馈连接**：装置**不能测电路输出**，只能纯前馈 + 测装置自身输出。电路输出只接示波器。
2. **一键启动、不可干预**；**启动后 5s 内出信号**。
3. 基本(3)(4) 电路输出误差 **≤5%**，而基本(1) H(s) 只保证 ≤10% → **必须实测 |H| 表**才够准。
4. 发挥(1)：2 分钟内学完，**不可用外部仪器**，显示滤波类型。
5. 发挥(2)：装置输入电阻 **≥100kΩ**；复现波形无失真、同频稳定、峰峰值误差 ≤10%；输入含**矩形波**（多谐波）→ 需实时滤波/建模复现。
