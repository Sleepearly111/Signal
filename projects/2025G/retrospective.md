## 1. 结论摘要

2025G 项目已经形成一套可运行的 STM32F407 电路模型探究装置原型，覆盖了题目的两条主线：

1. 对已知有源 RC 模型电路，根据传递函数或实测增益表反推装置应输出的幅值，再通过装置自身测量闭环校准输出；
2. 对未知 RLC 模型电路进行扫频学习，识别滤波器类型并拟合二阶模型，再对外部周期信号测频、识别波形、按模型修正各次谐波并由 DAC 重构输出。

项目的主要价值不只是最终程序，还包括 AD9833/AD603/AD8052 输出链、ADS8688 测量链、AD637 扫频测幅经验、STM32 内置 ADC/DAC+DMA 实时重构方案、串口诊断体系以及大量硬件联调边界。

当前状态应概括为：

- 基础部分的低频方案与关键频点已有实机验证，已知电路前馈控制路线成立；全频段尤其接近 1 MHz 的指标没有完整证据。
- 发挥(1)已经在低通实物上完成扫频、类型判断和模型拟合，但当前依赖 AD637 手动换线，且启动时仍装载临时预置模型，不是最终比赛流程。
- 发挥(2)已经完成正弦、矩形、三角类周期波形的识别、模型推理和 PA5 重构，已测目标中仅 **40 kHz正弦波**仍无法稳定定住；其余已测波形和频点已经完成。
- USART2 调试输出已成为可靠的工程诊断接口；串口屏的软件协议存在，但实际显示交互尚未形成可靠比赛操作界面。

因此，整机属于“核心方案和主要模块已硬件验证、比赛闭环尚未完全收口”，不能把整个项目统一标为“比赛可用”。

## 2. 状态口径

本报告采用以下四级状态，按证据逐项标注：

| 状态 | 含义 |
|---|---|
| 理论完成 | 方案、公式或代码路径已经形成，但没有足够的软件运行证据 |
| 软件验证 | 已编译、存在可执行构建产物，或通过串口数据验证了软件路径 |
| 硬件验证 | 已在 STM32 和实际信号链上观察到预期行为，但不一定覆盖题目全部边界 |

一个模块达到“硬件验证”不自动等于整机“比赛可用”；从项目中提取出的新库也不能继承原工程的硬件等级，必须重新验证。

## 3. 项目整体功能

### 3.1 题目目标

题目要求制作已知模型电路和电路模型探究装置，核心指标包括：

- 已知 RC 有源滤波器在 100 Hz～3 kHz 范围内符合给定传递函数；
- 装置可产生步进 100 Hz 的正弦信号，最高频率不低于 1 MHz，峰峰值能力不低于 3 V；
- 在不把已知电路输出反馈给装置的条件下，使已知电路输出达到指定幅值；
- 对未知 RLC 电路在 2 分钟内自主学习，显示低通、高通、带通或带阻类型；
- 学习后断开未知电路，由装置根据 1 kHz～50 kHz、2 Vpp 的外部周期信号推理并输出与未知电路相同的波形，要求同频稳定、无明显失真、Vpp 相对误差不超过 10%；
- 装置输入阻抗不低于 100 kΩ；基本(3)(4)和发挥(2)均有一键启动、后续不可人工干预等约束。

### 3.2 系统方案

基础部分采用“模型前馈 + 装置输出闭环”：

```text
目标电路输出 Vpp
        ↓ 除以 |H(f)|（实测表优先，理论公式兜底）
所需装置输出 Vpp
        ↓
AD9833 → AD603 → AD8052 → 装置输出 → 已知模型电路
                    ↑
        ADS8688只测装置自身输出并调节AD603
```

该架构遵守题目“已知电路输出不得反馈到装置”的限制。电路输出只给示波器观察，软件显示值是根据实测装置输出和已知增益估算的结果。

发挥部分分为学习和复现：

```text
学习A：DDS扫频 → 装置输出 → AD637 → ADS8688
       每点把输入校准到约2 Vpp并保存AD603设定

人工换线

学习B：DDS按原设定扫频 → 未知电路 → AD637 → ADS8688
       计算296点 |H(f)| → 类型判断 → 二阶模型拟合

复现：外部周期信号 → 抬升/限幅 → PB1 ADC(1 MSPS, 2048点)
       → 去直流/FFT/过零测频/波形识别
       → 各次谐波乘以模型幅频响应并叠加模型相位
       → 傅里叶合成一个周期 → PA5 DAC + TIM6 + DMA循环输出
```

复现频率按题目最小步进量化到 100 Hz。低于 10 kHz 时尝试数字 PLL；正弦波连续微调波表相位，矩形/三角波保持波表不变，仅在完整周期边界轻微改变 TIM6 分频。10 kHz 及以上关闭 PLL，使用固定量化频率，接受独立时钟造成的缓慢相位漂移。

### 3.3 硬件组成

| 器件/接口 | 项目用途 | 当前经验结论 |
|---|---|---|
| STM32F407ZGT6 | 168 MHz Cortex-M4F 主控 | 算力足以完成 2048 点 FFT、12 次谐波建模和 DAC DMA 输出 |
| AD9833 ×2 | 学习和基础部分的正弦 DDS | 10 MHz 实际时钟；双通道软件同步写入；频率输出已实机使用 |
| AD603 | 可编程增益放大 | PA4/DAC CH1 控制增益；当前拟合 `G(dB)=75.97×Vg-49.30`，原始五点数据未归档，仍需复测确认 |
| AD8052 | 固定增益输出级 | 软件按 5 倍处理，但配置中仍标为待实测；注意摆幅、带宽、负载和削顶 |
| ADS8688 | ±5.12 V、16 bit 幅值测量 | 低频和 AD637 直流输出可用；直接测高频交流时曾与示波器明显不符，且板上 CH0 被标记为坏通道，现主要使用 CH1/CH2语义 |
| AD637 | 真有效值/交流幅值转直流 | 解决 ADS8688 直接高频采样不稳定问题；需等待稳定，尤其 1 kHz 首点；只能测幅值，不能直接测相位 |
| PB1 / ADC1 | 发挥(2)外部波形采集 | TIM3 TRGO、DMA normal、1 MSPS、2048 点；输入必须经偏置/限幅保持在 0～3.3 V |
| PA5 / DAC CH2 | 发挥(2)重构波输出 | TIM6 触发、DMA 周期输出，16～128 点/周期，更新率上限 800 kSPS |
| PA4 / DAC CH1 | AD603 增益控制 | 0～3.3 V 控制；AD603 实际有效控制范围设置为 0.4～1.4 V |
| LTC1068 | 可编程低通/抗混叠候选 | PC6/TIM8 可输出时钟，代码默认按 CLK/fc=100；主流程未调用，未形成硬件验证证据 |
| USART1 | 串口屏 | 有 ASCII、简化二进制和旧协议兼容代码；实机界面仍不可靠 |
| USART2 | 调试串口 | 已用于学习和复现的详细中文日志，硬件调试价值高 |
| KEY0/KEY1 | 学习、换线继续、复现启动 | KEY0 启动/重新学习，Phase A 后换线由 KEY1继续；模型有效后 KEY1 启动复现 |

主要引脚映射：PB1=ADC1_IN9，PA4=DAC CH1/VGA，PA5=DAC CH2（代码配置），PE4=KEY0，PE3=KEY1，PA9/PA10=USART1，PA2/PA3=USART2，PC6=TIM8_CH1，PB12/PB13/PB15 与 PD12/PD13/PD15 分别连接两路 AD9833，PD0～PD5连接 ADS8688 控制/串行接口。

## 5. 实际验证情况

### 5.1 已有明确硬件证据

- AD9833能够按扫频状态机从1 kHz运行到60 kHz，并驱动后续增益链。
- AD603增益控制可调，已得到 `75.97 dB/V`、`-49.30 dB` 的五点拟合结果；PA4满幅按3.3 V处理。
- 已知电路100～3000 Hz的实测增益表已经写入工程，1 kHz实测增益约2.54，与理论约2.52接近。
- AD637学习低通时得到单调衰减曲线，曾记录1 kHz `|H|≈0.713`、5 kHz `≈0.486`、9 kHz `≈0.333`、60 kHz `≈0.060`，类型判断为低通。
- 稳定学习结果为 `type=1, K=0.7607, f0=34600 Hz, Q=0.150, err=0.0094`。这组参数已被临时固化用于反复调试复现，不能误认为每次上电都重新学习所得。
- PB1采样能识别3 kHz、10 kHz、30 kHz、40 kHz等正弦输入，过零测频结果通常接近信号发生器设定值。
- PA5 DAC能够输出对应频率的重构波；矩形波在8 kHz测试时峰峰值与未知电路较接近。
- 发挥(2)的其余正弦、矩形和三角波目标已经完成，目前仅40 kHz正弦波仍定不住。
- 100 Hz频率量化显著减少了DAC表长/分频在相邻采集帧间反复切换导致的跳变。
- USART2中文日志已经能报告原始输入、归一化、识别结果、模型、主频增益/相移、预计输出、DAC定时和PLL状态。

### 5.2 尚未达到比赛可用的项目

- 未形成覆盖基础(2) 100 Hz～≥1 MHz的全频点幅值和频率验收表。
- 基础(3)(4)虽有实测LUT，但缺少全部频率/目标电压组合的最终≤5%验收记录。
- 未知电路学习仍需把AD637从装置输出手动换到电路输出，不满足单学习键后无需人工干预的最终形态；模拟开关尚未接入。
- 当前启动默认装载一个低通预置模型，KEY1可直接复现；这是调试便利，不是比赛时对未知电路自主学习的合规行为。
- 高通、带通、带阻三类未知电路没有与低通同等级的硬件回归证据。
- AD637只能提供幅值，学习到的相位来自二阶理想模型；运放、抬升、ADC和输出缓冲带来的附加相位没有实测入模。
- 发挥(2)仅剩40 kHz正弦波的同屏稳定问题；其余已测波形和频点已经完成。40 kHz处仍会因独立时钟微差、每周期DAC点数较少且高频PLL关闭而漂移。
- 复现输入幅值依赖“题目信号恒为2 Vpp”的假设进行归一化；抬升电路后的PB1实测Vpp常只有约1.4～1.7 V，不能据此直接判断原信号幅值准确。
- 串口屏未完成可靠实机交互，当前比赛操作仍依赖实体按键与调试串口。
- 没有输出缓冲/电平转换最终验收资料。PA5内置DAC直接输出0～3.3 V带1.65 V偏置，接负载后的幅值、带宽和驱动能力需要独立确认。

## 6. 调试经验总结

| 遇到的问题 | 原因分析 | 最终处理/当前处理 | 关键经验或参数 |
|---|---|---|---|
| 原`build/Debug`无法全量CMake构建 | CMake缓存仍指向搬迁前路径，且记录的STM32Cube Ninja已不存在 | 保留旧缓存不删除，建立`build/current-debug`作为当前构建目录 | 构建缓存含绝对路径，工程移动后应重新配置新目录，不要把旧缓存当源码问题 |
| ADS8688串口值与示波器高频幅值差异大 | 直接采高频交流受采样时序、SPI吞吐、通道切换、前端带宽和采样相位影响 | 学习测幅改用AD637把交流RMS转为慢变直流，ADS8688只读直流 | 高精度ADC不等于高频波形采集器；先核算有效采样率和模拟带宽 |
| Phase A后电路输出出现十几伏/失真 | 接线把未知电路或测量链错误地并入输出，负载/反馈关系改变；高增益链可能饱和 | 明确Phase A只测装置输出，未知电路输出不应参与；换线前将VGA置安全增益 | 学习两阶段必须有明确接线图、隔离和安全增益状态 |
| 输出了两次LEARN:A | 状态/按键流程曾让Phase A被再次启动，错误接线下又重新校准输入 | 修正状态机和按键语义；Phase A结束只允许KEY1进入Phase B | 长状态机必须拒绝重复Start，并打印当前阶段 |
| Phase A高频Vin越来越小、示波器输出越来越大 | AD603被算法不断增益补偿，AD637/通道读数未正确反映真实输出或链路进入带宽/饱和区 | 限制学习校准增益最大4倍，检查通道和AD637输入，异常值不再盲目放大 | 任何幅值闭环都要有最小有效读数、最大增益、削顶检测和故障退出 |
| Phase B刚换线时1 kHz持续漂移 | AD637输出、耦合电容或未知电路建立时间远大于单次ADC转换；首次频点带有前阶段历史 | 增加1.5 s预热，每250 ms检查一次，连续3次变化≤2%才保存，最多16次 | 慢响应测量器必须按物理时间常数等待，不能只增加ADC平均次数 |
| 延长Phase B后模型曾错误变成带通 | 当时1 kHz保存到过低且不稳定的值，低端/高端分类依据被污染 | 修复接线/等待后低通曲线恢复；使用边缘多点平均而非单点 | 分类结果异常先看原始曲线，不能先调分类阈值掩盖测量错误 |
| 模型`f0=33.8/34.6 kHz`看似与5 kHz截止频率矛盾 | 使用的是低Q二阶参数化；当Q=0.15时，f0不是-3 dB截止频率 | 用完整幅频函数比较，而不是把f0直接当截止频率 | 模型参数名称必须说明物理含义；应额外报告由模型计算的-3 dB点 |
| PB1测得1.6 Vpp但信号源设为2 Vpp | 输入经过抬升/衰减/限幅网络，ADC看到的是变换后波形 | 题目已知输入恒2 Vpp时，用实测波形识别频率/谐波，再整体归一化到2 Vpp | 幅度标定应记录前端传递比例；“0～3.3 V范围”不代表满量程映射恰好为2 Vpp |
| DAC频率正确但两路波形漂移 | 信号发生器与STM32的时钟独立，即使显示频率同为整数，微小频差也会积累相位 | 频率量化到100 Hz；低频增加DPLL，高频保持固定频率以避免噪声拉扯 | 同频显示不等于同相稳定；0.2 Hz误差在数秒内就能看出漂移 |
| 连续重启DAC导致波形跳变/多重轨迹 | 每帧频率或波形签名变化触发停止DMA、重建表和重启定时器 | 只有表长、分频、波形类型或PLL模式真正变化时才重启，并增加DAC启动计数日志 | 流式输出的首要原则是保持定时器/DMA连续运行 |
| NCO/双缓冲方案出现“双螺旋”和大量重叠 | 相位推进、缓冲边界和输入参考不同步，调试复杂度超过当时可控范围 | 两次实验后均回退，恢复单周期DMA波表 | 高风险实时架构应先用离线仿真和逻辑分析仪验证再上整机 |
| 5.4 kHz三角波特别难锁 | 动态表长/整数分频仍有约0.19 Hz固有误差；三角波相位判据、高次谐波和低频PLL校正能力共同影响 | 增加DMA剩余计数+TIM6 CNT的分数播放位置、周期边界nudge和分级纠偏 | 特定频点问题通常来自整数定时可实现性，不一定是“题目陷阱” |
| PLL能拉住一会，漂过半周期又快速对齐 | 校正能力不足、误差进入大区间后触发较强纠偏，表现为周跳/周期性重对齐 | 采用死区4°，误差>15°/45°时请求2/4个纠偏周期；效果仍需硬件复验 | 应分别记录频率误差、相位误差、重启次数和纠偏方向，不能只看示波器轨迹 |
| 10 kHz以上PLL越调越乱 | 1 MSPS下每周期样本减少，ADC前端相位误差和处理延迟使相位检测噪声增大 | 当前10 kHz以上关闭PLL，保持100 Hz量化的固定DAC频率 | 纯软件闭环受参考相位质量限制；高频要稳定同屏，优先使用比较器+定时器输入捕获或共享时钟 |
| 矩形波重构不如原波平滑/边沿尖峰 | 未知低通会衰减高次谐波；软件只保留最多12次谐波，DAC点数和输出带宽也有限 | 保持傅里叶重构并接受带限波形；避免在DMA运行时频繁改波表 | 对滤波器输出应比较目标电路后的波形，而不是要求保留信号源原始方沿 |
| 输出Vpp曾普遍高于未知电路 | 模型幅值、2 Vpp归一化、DAC/缓冲增益和示波器测量口径可能不一致 | 用串口同时打印基波幅度、合成Vpp和模型增益，逐段核对 | 区分峰值、基波幅度、合成Vpp、RMS；标定必须以最终输出端为准 |
| 串口输出出现乱码或问号 | 中文UTF-8、多字节串口吞吐、终端编码和大量同步打印共同影响 | 保留中文诊断但按1 s节流；比赛版应确认终端编码或提供纯ASCII简表 | 调试日志不能阻塞实时链；详细日志和比赛日志应分级 |

## 9. 硬件经验总结

### 9.1 器件选择

- AD9833适合扫频和基础正弦源，但输出幅度小、时钟和高频幅值衰减必须实测；双芯片同步写入不等于相位严格同步。
- AD603适合程序控制幅值，但控制电压与dB增益关系必须在实际接法、供电和负载下标定。控制脚是增益控制输入，不是信号输入。
- AD8052可作高速输出缓冲/固定增益，但“标称5倍”不能代替实测。要同时检查增益带宽、压摆率、输出摆幅和负载驱动。
- ADS8688的16 bit和±输入范围适合慢速精密幅值/直流量，不能在没有足够采样率和正确SPI时序时承担高频波形采集。
- AD637把高频交流测幅问题变成低速直流测量，显著提高稳定性，但带来建立时间、频率响应和只能测幅不测相的限制。
- STM32F407内置ADC+DMA适合发挥(2)的1 MSPS识别链，内置DAC+DMA适合低成本周期重构；高频时每周期点数有限，外接高速DAC会提高波形质量但增加工程复杂度。
- LTC1068只有在时钟比、截止频率、供电和前后级阻抗全部确认后才有意义；它可以平滑DAC阶梯和抗混叠，但不能解决两台独立时钟的相位漂移。

### 9.2 接线与调试注意事项

- 所有仪器、STM32和模拟板必须共地，但模拟地/数字地应规划回流路径，避免DDS/串口/DMA噪声进入测量前端。
- 每个芯片电源脚就近放置约0.1 µF去耦，板级再放约10 µF储能；AD603控制线和AD637输出尤其要远离数字时钟。
- 基础(3)(4)时，已知电路输出只能接示波器，不能回接装置；装置闭环只能测自己的输出。
- AD637两阶段手动流程必须在换线前降低VGA增益，先断信号再换线，确认装置输出和未知电路输出没有被错误并接。
- 示波器探头的1×/10×设置、50 Ω/高阻端接、AC/DC耦合会直接改变Vpp读数；每轮标定前应固定并记录。
- PB1前端必须把负电压变换到0～3.3 V并留出裕量。抬升不应简单削顶；最好用已知线性比例和1.65 V偏置，并验证100 kΩ输入阻抗要求。
- 如果未来加入过零比较器，输出必须转换到STM32可接受的0～3.3 V，不能把±4.8 V直接接入PA1/任意GPIO；应使用比较器开漏上拉、电平转换或限幅保护。
- 高频同屏稳定的根本方案是提供可靠硬件相位参考：比较器输出接定时器输入捕获，或让输入源与DAC共享/锁定时钟。AD630可用于模拟相位检测，但不能替代安全的数字电平接口。
- PA5最终输出建议增加合适的高速缓冲、偏置去除/电平转换和重构低通，并以最终接口端而不是DAC引脚完成幅值标定。

### 9.3 标定资料应如何保存

本项目最大的资产缺口之一是“拟合参数保留了，原始测量点没有保留”。未来每次硬件标定至少保存：

- 日期、板号、供电、温度、探头与端接方式；
- 测试频率、输入Vpp、输出Vpp、控制电压实测值和DAC码；
- 增益倍数、dB值、是否削顶、拟合残差；
- 原始表格和拟合脚本，而不只把最终斜率/截距写入头文件；
- 示波器截图或串口原始日志，以及对应固件commit/工作区指纹。

如果以后需要把该原型真正收口为比赛版本，应按以下顺序验收；这不是本次复盘的实施任务：

1. 取消启动时的临时预置模型，确保比赛路径必须先完成自主学习。
2. 用模拟开关或合规硬件自动完成Phase A/B测量切换，消除手动换线和第二次按键干预。
3. 对高通、带通、带阻各准备至少一个RLC实物，重复完整296点学习并形成分类混淆表。
4. 用网络分析或双通道示波器记录幅频和相频，对比AD637幅值+理想二阶相位的误差。
5. 给PB1抬升前端做幅度、相位、带宽和输入阻抗标定；确认2 Vpp输入不会削顶。
6. 补齐发挥(2)已完成频点的正式测试记录，并针对40 kHz正弦波单独记录Vpp误差、频差、漂移速度和失真。
7. 对40 kHz正弦波优先增加可靠的高频相位参考，或验证输入捕获/共享时钟方案；保留现有低频PLL参数作为已完成方案。
8. 完成PA5输出缓冲/去偏置/重构滤波，并在最终接口端标定。
9. 完成串口屏实机协议、误触防护、状态提示和一键操作验收。
10. 最后才进行基础(2)全频扫频、基础(3)(4)全组合和发挥(1)(2)计时验收，形成正式测试记录。

## 11. 最终资产判断

2025G最值得保留的工程资产是：

- 已知模型“实测增益表前馈 + 装置自身输出闭环”的合规控制思路；
- AD9833、AD603、AD8052和ADS8688组成的可调输出/测量链及其失败边界；
- AD637两阶段扫频学习、首点稳定判断和二阶滤波器拟合流程；
- 1 MSPS ADC采集、FFT/过零测频、谐波模型推理、动态周期波表和DAC DMA输出的完整原型；
- 频率量化、避免DAC重启、相位/幅值分离诊断等实时系统调试经验；
- 详细中文串口诊断字段和以原始数据判断问题、而不是只看最终类型的调试方法。

最需要谨慎对待的部分是：当前低通预置模型、手动换线、AD603缺失的原始标定点、ADS8688高频直测能力、理想模型相位、40 kHz正弦波漂移和串口屏。它们可以作为后续研究记录，但不能作为已经比赛验收的结论，也不应原样提取进公共库。
