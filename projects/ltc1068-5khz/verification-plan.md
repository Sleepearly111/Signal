# LTC1068 5 kHz 验证计划

## 软件

- CubeMX 生成工程后，使用当前工程工具链构建，记录命令、返回码、Flash/RAM 和警告。
- 上电后串口输出实际定时器时钟和目标 `fc=5000 Hz`。
- 示波器确认 `S_CLK` 约为 500 kHz、占空比约 50%。

## 硬件

- LTC1068 使用 +5 V/GND/-5 V 供电。
- 外部信号发生器先输出正弦波，输入幅度从 0.5~1 Vpp 开始。
- 在 100 Hz、1 kHz、5 kHz、10 kHz、20 kHz、40 kHz 记录 `S_IN` 和 `S_OUT` 的 Vpp。
- 每个点记录示波器端接方式、输入 Vpp、输出 Vpp 和衰减比。

## 边界

截止频率的最终结论必须来自实测幅频数据；500 kHz 时钟只提供理论设定，不替代模块实际验证。
