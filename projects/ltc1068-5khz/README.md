# LTC1068 · 5 kHz 低通试验

| 接线 | 目的 |
| --- | --- |
| PC6 / TIM8_CH1 → 模块 S_CLK | 目标 500 kHz、约 50% 占空比。接前先核对模块允许的时钟电平 |
| 信号源 → 模块 S_IN | 输入小幅正弦，先确认共地和偏置 |
| 示波器 CH1 → S_IN，CH2 → S_OUT | 统一探头倍率与负载后比较幅值 |
| STM32 与滤波模块共地 | 电源按模块板上实际规格连接 |

项目按 100:1 模块配置估算 5 kHz 截止频率。具体芯片后缀与模块时钟分频比应由实物或厂商资料确认。先测时钟，再扫输入频率并观察相对通带增益约 −3 dB 的频点。
