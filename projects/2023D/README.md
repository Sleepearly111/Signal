# 2023 D · 信号调制方式识别与参数估计

[历届试题](https://nuedc.org/problems/#2023) · [应用层代码](source/)

## 信号链与接线

| 分支 | 器件和接法 | 作用 |
| --- | --- | --- |
| 前端 | 信号输入先进入 AD603 变增益前端 | 在样机线性范围内获得比较器与包络链可用的幅度 |
| 频率 | AD603 → TLV3501 比较器 → STM32 PC6 / TIM8_CH1 | 定时器捕获、DMA 和周期估计 |
| 包络 | AD603 → BAT54 检波 → RC → 偏置和限幅 → PB1 / ADC1_IN9 | 采集包络及计算调制信息 |
| 参考与开机检查 | 分别观察比较器阈值、包络直流工作点和 ADC 满量程 | 记录探头负载与码值标定 |

从 [CubeMX 配置](source/app.ioc) 查引脚，在 `source/User/` 查采集、包络和判决代码。历史来源基线为 `7b15a78`。模拟前端的阈值、抬升与标定随样机变化，接线时先核对模块电源和输出范围。

## 验证

项目复盘记录了约 2 MHz 连续载波的捕获、CW/AM 判别和 1 kHz/5 kHz AM 调制频率试验。档案还包含 FM、2ASK、2FSK、2PSK 的实现或探索，完整参数覆盖和重复误差记录待积累。

应用层快照须配合对应板级工程。部分旧工程引用上游加窗实现，复原工程时请按其来源和许可取得对应实现。
