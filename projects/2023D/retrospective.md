## 1. 项目简介

### 1.1 题目目标

装置接收信号发生器产生的2MHz、100mVpp调制信号，完成以下任务：

- 自主识别CW、AM、FM；
- 估计AM调制度 \(m_a\)、调制频率 \(F\)；
- 估计FM调频指数 \(m_f\)、最大频偏 \(\Delta f_{\max}\)、调制频率 \(F\)；
- 发挥部分识别2ASK、2FSK、2PSK；
- 估计数字调制码速率 \(R_c\)，并在2FSK时估计移频键控系数 \(h\)；
- 显示识别与估计结果；
- 从单一端口输出可供示波器观察的解调波形。

题目给定的离散候选参数对实现有重要影响：

- AM/FM调制频率为1、2、3、4、5kHz之一；
- 数字调制使用NRZ码；
- 码速率为6、8、10kbps之一；
- 输入载波频率为2MHz、幅度为100mVpp。

因此，本工程没有追求任意频率下的通用调制分析仪，而是针对题目给定候选集合设计低计算量、可快速判决的识别装置。

### 1.2 核心设计思想

STM32F407不直接高速采样并完整重建2MHz模拟载波，而是先用模拟电路将信息转换成两类容易测量的特征：

- 包络通道提取幅度变化；
- 比较器与定时器通道提取边沿时间、瞬时频率和相位异常。

MCU随后融合这两类特征完成分类和参数估计。

这条路线的本质是：

> 先用模拟前端降低问题维度，再让MCU处理低频包络和数字边沿。

## 3. 硬件设计

### 3.1 AD603可变增益前端

输入信号只有100mVpp，直接送入包络检波器和比较器时，信号幅度、检波压降和噪声裕量都不理想，因此使用AD603进行前置放大。

当前源码通过STM32的DAC2（PA5）给AD603的GPOS提供控制电压：

- DAC码值：1100；
- 控制电压约0.886V；
- 按工程采用的关系式，对应增益约18dB。

调试期间曾比较17dB和20dB工作点：

- 增益过低会使包络变化量和比较器信噪比下降；
- 增益过高可能导致后级削顶、包络失真和比较器错误翻转；
- 因此AD603增益不是越大越好，而应以“不削顶且两路均有足够裕量”为准。

当前18dB只代表该样机的折中工作点。更换AD603模块、输入幅度、负载、检波器或供电后，应重新观察输出峰峰值和上下端裕量。

### 3.2 频率检测链

频率检测链为：

```text
AD603 → TLV3501 → PC6/TIM8_CH1 → DMA Capture
```

TLV3501将模拟载波转换为数字方波，STM32不必采样2MHz正弦波的幅值，只需记录方波边沿到达时刻。

TIM8工作要点：

- TIM8计数时钟为168MHz；
- PC6配置为TIM8_CH1输入捕获；
- 输入捕获预分频为DIV8，即每8个上升沿记录一次；
- 捕获值由DMA2 Stream2写入`cap_buf`；
- 40ms、2MHz连续载波理论捕获点数约为：

\[
N_{\mathrm{cap}}
=2\,\mathrm{MHz}\times40\,\mathrm{ms}/8
=10000
\]

板上结果与理论值一致：

- `cap≈10000`；
- 捕获间隔约为670多个TIM8时钟；
- 计算所得载频约为2MHz。

该结果说明AD603、TLV3501、PC6复用、TIM8输入捕获和DMA搬运形成了完整闭环。

### 3.3 包络检测链

包络检测链为：

```text
AD603 → BAT54 → RC → ENV_RAW → 抬升 → ENV_ADC → PB1/ADC1_CH9
```

各级作用如下：

- BAT54对高频载波进行整流；
- RC网络滤除2MHz载波分量，保留1～5kHz包络变化；
- `ENV_RAW`是检波后的低频包络；
- 抬升电路给包络增加直流工作点，使其落入STM32 ADC允许的0～3.3V范围；
- PB1上的ADC1_CH9采集抬升后的`ENV_ADC`。

包络链存在两个相互制约的时间常数要求：

- RC太小：残留2MHz纹波较大；
- RC太大：1～5kHz包络被衰减，尤其5kHz更明显。

因此包络检波不能只看“是否有电压”，还应同时检查：

- CW时输出是否近似稳定；
- AM时包络是否连续且不削顶；
- 1kHz和5kHz时包络幅度是否仍有可分辨度；
- 包络谷底是否受到二极管压降、后级负载和抬升电路限制。

### 3.4 抬升与比较器工作点

单电源STM32 ADC不能接收负电压。包络输出和比较器输入的工作点必须根据实际电路安排，而不能只根据示波器“看起来有波形”判断。

调试中曾出现以下问题：

- AD603输出未处于TLV3501比较门限附近，比较器输出成为固定直流；
- 串联电容后没有建立可靠的1.65V偏置回路，信号表现为被滤掉或工作点漂移；
- 使用OPA227构成的隔直/缓冲电路在2MHz下产生异常波形和杂散。

最终经验是：

1. 串联电容只能隔离直流，不能单独产生1.65V偏置；
2. 电容后必须有明确的偏置电阻网络和输入回路；
3. 运放的增益带宽、压摆率、输入输出摆幅和稳定性必须覆盖2MHz载波；
4. 如果某一级会破坏载波形状，应优先简化链路并用示波器逐级确认；
5. 抬升后再分给比较器和包络支路时，要检查两路负载是否相互影响。

### 3.5 ADC采样链

ADC采样配置为：

- ADC1_CH9，输入引脚PB1；
- TIM3更新事件TRGO触发；
- TIM3周期为419，得到200kSa/s采样率；
- DMA2 Stream0，Normal模式；
- 每次采集8000点；
- 固定采集窗口40ms。

200kSa/s对于1～5kHz包络具有充足的时间分辨率。40ms窗口的频率分辨尺度约为25Hz，同时包含：

- 1kHz信号40个周期；
- 5kHz信号200个周期。

因此对题目规定的五个离散候选频率进行Goertzel检测是合适的。

## 4. 软件架构

### 4.1 模块划分

当前应用层主要模块如下：

| 模块 | 主要职责 |
|---|---|
| `capture.c/.h` | 同步启动ADC DMA与TIM8捕获DMA，维护40ms采集窗口和质量状态 |
| `inst_freq.c/.h` | 将捕获计数转换为瞬时频率，分析短间隔、长间隔和异常边沿 |
| `stats.c/.h` | 计算包络和频率序列的百分位数、中间样本比例等统计量 |
| `classify.c/.h` | 融合包络谱峰、包络分布、有效频率点数和频率游程完成分类 |
| `estimate.c/.h` | 根据调制类型估计 \(F,m_a,m_f,\Delta f,R_c,h\) |
| `demod_out.c/.h` | 生成DAC输出缓冲并通过DMA循环输出解调波形 |
| `hmi.c/.h` | USART1串口屏命令、启动帧接收和结果显示 |
| `main.c` | 状态机、诊断输出、多次采集平均和模块调度 |
| `app_config.h` | 采样率、候选参数、分类阈值和缓冲长度 |

### 4.2 双通道DMA采集

一次采集按以下顺序启动：

1. 启动TIM8输入捕获DMA；
2. 启动ADC DMA；
3. 启动TIM3，使TIM3 TRGO以200kHz触发ADC。

ADC完成8000点后到达40ms窗口终点。在ADC完成回调中只做：

- 停止TIM3；
- 读取TIM8 DMA剩余数量；
- 冻结TIM8与DMA；
- 设置窗口结束标志。

统计计算放在主循环的`Capture_Service()`执行，避免在中断中遍历约10000个捕获点。

这种设计解决了两个问题：

- 包络路和频率路共享同一测量时间窗；
- 2ASK低电平期间即使没有边沿，也不会阻塞ADC窗口结束。

采集层还记录：

- 实际捕获点数；
- 理论点数和捕获比例；
- 零间隔、过短间隔、过长间隔；
- 缓冲区是否提前装满；
- EMPTY、PARTIAL、CONTINUOUS、TRUNCATED等质量状态。

这些诊断量既用于调试，也为ASK低电平丢边沿等现象提供特征。

### 4.3 瞬时频率计算

TIM8捕获到的是16位计数器值。程序先计算相邻捕获值的无符号差，再将连续5个捕获间隔合并：

- 每次硬件捕获覆盖8个载波周期；
- 每个瞬时频率点合并5次捕获；
- 因此一个频率点平均覆盖40个载波周期。

计算公式为：

\[
f_i=
\frac{f_{\mathrm{TIM8}}\times8\times5}
{\sum_{k=0}^{4}\Delta T_k}
\]

这里 \(f_{\mathrm{TIM8}}=168\mathrm{MHz}\)。

40周期平均能够抑制比较器抖动和单边沿量化误差。程序同时过滤：

- 零间隔；
- 小于最小载波间隔阈值的异常短间隔；
- 大于最大间隔阈值的丢边沿或ASK低电平间隔。

过滤后的序列用于稳定载频和频率调制分析；原始间隔统计则保留给ASK、PSK和硬件质量诊断。

### 4.4 包络统计与Goertzel

包络通道使用两类特征。

第一类是稳健幅度统计：

- \(p_5\)、\(p_{50}\)、\(p_{95}\)；
- 包络相对起伏：

\[
r_{\mathrm{env}}
=\frac{p_{95}-p_5}{(p_{95}+p_5)/2}
\]

使用百分位数而不是绝对最大值和最小值，可以降低个别毛刺对分类的影响。

第二类是候选频率Goertzel：

- 去除包络均值；
- 分别计算1、2、3、4、5kHz的归一化幅值；
- 选择幅值最大的候选频率作为 \(F\)。

由于题目只要求五个离散候选，Goertzel比完整FFT更直接，也减少了运算量和内存使用。

### 4.5 分类算法

当前分类逻辑可概括为：

```text
包络中是否存在明显的1～5kHz稳定单音？
    是 → AM
    否
       ↓
有效频率点是否因断载波明显减少？
    是 → 2ASK
    否
       ↓
包络是否明显起伏？
    是 → 按中间幅度样本比例区分AM与2ASK
    否
       ↓
分析瞬时频率偏离中位数的游程
    持续偏离 → FM或2FSK
    孤立异常 → 2PSK
    无明显变化 → CW
```

AM与2ASK不能仅通过“包络是否变化”区分，因为两者都有幅度变化：

- AM包络连续、平滑，并在一个候选频率上形成稳定单音；
- 2ASK包络主要集中在高低两个电平，低电平码元期间载波边沿可能消失。

当前工程因此综合：

- 包络候选频率谱峰；
- 有效瞬时频率点数；
- 包络中间幅度样本比例。

### 4.6 AM调制度估计

理想AM调制度可由包络极值得到：

\[
m_a=\frac{A_{\max}-A_{\min}}{A_{\max}+A_{\min}}
\]

但当前实际链路包含：

- BAT54二极管非线性；
- RC频率响应；
- 抬升直流偏置；
- AD603增益误差；
- 后级负载和ADC量化；
- 高调制度时包络谷底失真。

因此工程没有直接把理想公式作为最终输出，而是先计算：

\[
\mathrm{raw}=\frac{p_{95}-p_5}{p_{50}}
\]

再用当前样机的实测点进行分段线性标定。现有源码中的标定点为：

| 真实 \(m_a\) | raw |
|---:|---:|
| 0.30 | 0.0198 |
| 0.40 | 0.0211 |
| 0.60 | 0.0258 |
| 0.70 | 0.0553 |
| 0.80 | 0.0666 |
| 0.90 | 0.0687 |

0.60～0.70之间出现明显跳变，说明模拟前端在该区域并非理想线性系统。因此，这组系数只能视为当前样机的查表标定，不能直接迁移到其他硬件。

为了降低模拟波动，AM识别后自动进行20次40ms采集，并对20次 \(m_a\) 结果求平均后显示。

### 4.7 解调输出

PA4/DAC1通过DMA循环输出解调结果。当前AM路径不是直接把带噪包络逐点送出，而是：

1. 根据估计出的 \(F\) 对包络做正弦拟合；
2. 生成每周期64点的正弦表；
3. 设置TIM7更新速率；
4. 由DAC DMA循环输出稳定正弦。

这样能够得到更稳定、峰峰值满足观察要求的波形，但它属于“根据检测结果重建解调信号”，不是模拟包络原样复制。复盘和答辩时应明确说明这一点。

### 5.1 单次测量流程

```text
按下KEY0或串口屏Start
        │
        ▼
停止上一轮DAC输出，重设AD603控制电压
        │
        ▼

        │
        ▼
采集40ms：
  env_buf[8000]
  cap_buf[约10000]
        │
        ▼
计算捕获质量与原始间隔统计
        │
        ▼
cap_buf → 40周期平均 → freq_seq
        │
        ▼
包络谱峰、包络起伏、频率游程等特征
        │
        ▼

        │
        ▼
按类型估计参数
        │
        ├─ AM：自动重复20次并平均ma
        ▼
串口屏显示 + USART2诊断 + DAC输出
```

### 5.2 CW/AM判决

CW和低调制度AM的包络峰峰值可能接近，因此最终没有只依赖`env_ripple`：

```text
若1～5kHz候选处存在稳定包络谱峰
    → AM
否则若包络起伏很小、频率稳定
    → CW
```

实测中CW候选谱峰远低于低调制度AM，因此稳定单音特征比单纯峰峰值更可靠。

### 5.3 AM/2ASK判决

高调制度AM在包络谷底可能让TLV3501短暂丢失边沿，使有效频率点数量下降，表现得像2ASK。为解决这一问题，分类顺序调整为：

```text
先检查稳定的AM包络单音
再使用有效频率点数量判断2ASK
```

即使AM谷底导致比较器丢边沿，只要包络仍具有稳定的1～5kHz正弦成分，就优先判定AM。

当没有稳定包络单音时，再使用以下特征判断2ASK：

- 有效频率点数量明显少于连续载波；
- 包络主要分布在高低两个电平；
- 中间幅度样本比例较低；
- 原始捕获中存在断载波造成的长间隔。

## 6. 调试过程

### 6.1 初始问题：双通道都没有形成有效输入

早期日志出现：

- `cap=0`，TIM8没有捕获到比较器边沿；
- `ENV_ADC`只有约1.5V直流偏置和很小噪声；
- 切换AM参数后ADC统计没有相应变化。

定位方法不是立即修改分类代码，而是用示波器逐级检查：

```text
信号源输出
→ AD603输出
→ 包络检波输出
→ 抬升输出/PB1
→ TLV3501输入
→ TLV3501输出/PC6
```

结果表明问题主要出在模拟链路连接和工作点，而不是Goertzel本身。

### 6.2 `ENV_BIAS_ADC`错误导致AM无法分类或估计异常

早期代码把`ENV_BIAS_ADC`设为0，而实际抬升后的ADC中位值约为1914。由此产生两类问题：

1. 如果使用`p50-ENV_BIAS_ADC`归一化，错误偏置会改变`env_ripple`尺度；
2. 如果直接套用理想包络极值公式，直流抬升会进入分母，使 \(m_a\) 严重失真。

调试后记录当前样机的偏置约为1914 ADC码，并且最终的 \(m_a\) 不再单纯依赖减偏置后的理想公式，而采用实际`raw`到 \(m_a\) 的分段标定。

经验：

> 直流偏置既是ADC安全工作点，也是算法坐标系的一部分。硬件工作点变化后，软件归一化和标定必须同步更新。

### 6.3 `env_ripple`计算与固定阈值问题

初始分类过度依赖包络相对起伏：

- 阈值过高：低调制度AM被当作CW；
- 阈值过低：CW噪声被当作AM；
- 改变AD603增益或包络偏置后，旧阈值立即失效。

解决过程：

1. 使用 \(p_5,p_{50},p_{95}\) 代替绝对极值，降低毛刺影响；
2. 记录CW和不同 \(m_a\) 下的实际包络统计；
3. 引入1～5kHz包络谱峰作为更强的AM证据；
4. 将`env_ripple`降为辅助判据，而不是CW/AM的唯一判据。

### 6.4 CW误判AM

AD603增益、检波纹波和噪声会使CW包络产生非零起伏。曾出现CW的`raw`和低调制度AM接近，从而被判为AM。

解决方法是比较候选频率能量：

- CW的小幅变化主要是噪声和残余载波，不会稳定集中在指定调制频率；
- AM即使幅度较小，包络仍在某个1～5kHz候选频率上形成稳定峰值。

基于实测数据设置包络单音门限后，CW可稳定回落到默认的连续载波类别。

### 6.5 低调制度AM误判CW

20%～30%附近的AM包络变化较小，仅凭`env_ripple`容易低于阈值。

调试中分别采集CW以及20%、30%、40%、50%、80% AM的候选频率谱幅：

- CW最大值约为 \(2.1\times10^{-4}\)；
- AM 20%在1kHz处约为 \(4.99\times10^{-3}\)；
- 随调制度上升，1kHz谱峰总体继续增加。

据此采用归一化包络谱峰识别低调制度AM，使“小但稳定的周期变化”与“随机小噪声”分开。

### 6.6 高调制度AM误判2ASK

AM调制度较高时：

\[
A_{\min}=A_c(1-m_a)
\]

当 \(m_a\) 接近1，包络谷底接近零，TLV3501可能暂时失去有效翻转。此时：

- 捕获点数下降；
- 出现长间隔；
- 有效瞬时频率点减少；
- 特征与2ASK低电平码元相似。

旧判断顺序先看有效频率点数，因此60%以上AM曾被判成2ASK。

最终将AM稳定单音判断放到ASK点数判断之前：

```text
稳定正弦包络证据成立 → AM
否则再根据断载波和二电平特征判断2ASK
```

### 6.7 AM偶发误判FM或2PSK

比较器门限附近的抖动、包络谷底和模拟杂波会产生异常边沿，瞬时频率序列可能出现：

- 假的持续偏移；
- 少量孤立尖峰；
- 不合理的频率百分位范围。

如果过早进入频率分类，AM可能偶发成为FM或PSK。

解决思路包括：

- AM包络证据优先于频率游程；
- 40个载波周期平均生成一个瞬时频率点；
- 过滤过短、过长捕获间隔；
- 将复杂统计放到主循环而不是ISR；
- AM采用多次采集，减少单次模拟波动的影响。

### 6.8 AM调制频率误判

低调制度或包络链噪声较大时，曾出现真实1kHz却选择其他候选频率的情况。根因通常不是采样点不足：

- 200kSa/s、40ms窗口对1～5kHz已经足够；
- 主要问题是ADC中真正的包络交流分量太弱，噪声候选峰超过了目标频率。

处理方式是先改善模拟前端和包络信噪比，再使用去均值后的Goertzel候选扫描。1kHz和5kHz最终均得到正确结果。

### 6.9 \(m_a\)理想公式失效

早期标定基于不同输入幅度或不同AD603增益，硬件工作点改变后，原有系数失效。重新测量时还发现0.60～0.70之间`raw`存在明显非线性跳变。

最终处理：

- 固定输入载波、AD603增益和前端接线；
- 对题目有效范围内多个 \(m_a\) 点采集`raw`；
- 使用分段线性插值；
- 最终结果进行20次平均；
- 将输出限制在0～1。

这使当前样机能够给出可用结果，但也证明：

> 模拟前端变化后必须重新标定，不能把当前分段系数当作算法常数。

### 6.10 AD603输出杂波与隔直电路

调试中发现：

- AD603直接输出波形正常；
- 接入由OPA227组成的隔直/缓冲级后，2MHz波形出现明显杂波和不稳定；
- 去掉该级后，AD603输出恢复正常。

主要教训：

- 低频精密运放不一定适合直接处理2MHz载波；
- 示波器连续采集下的“波形很厚”可能是触发不稳定、相位漂移或真实高频振荡，需要单次采样和逐级旁路交叉确认；
- 隔直电容后必须有偏置回路，不能把“隔直”和“自动抬升到1.65V”混为一谈；
- 每加入一级模拟电路，都应重新检查增益、带宽、负载、直流工作点和稳定性。

### 6.11 解调输出不稳定与波形重建

直接输出原始包络时，包络纹波、ADC噪声和触发不同步会在示波器上表现为杂乱或波形变厚。

最终AM输出改为根据估计频率进行正弦拟合与DAC重建，并增加每周期采样点数，使输出更平滑。

仍需注意：

- DAC阶梯是离散采样的正常结果；
- 高频毛刺可能来自DAC更新沿、供电、地线和探头回路；
- 适当的模拟低通可以平滑DAC阶梯，但不应为了使用某个模块而盲目加入滤波器；
- LTC1068曾作为实验性输出滤波方案考虑，后因引入额外时钟、供电和链路风险而撤回，不属于当前最终链路。

### 7.3 当前限制

1. 分类阈值依赖当前样机噪声、增益和偏置。
2. AM标定曲线依赖当前模拟前端，不能直接跨板复用。
3. Goertzel只扫描题目给定候选频率，不是连续频率估计器。
4. 高调制度AM与2ASK在“载波边沿消失”特征上存在重叠，必须依赖包络形状和判断优先级。
5. 固定周期码型的2ASK也可能产生强包络谱线，后续若追求更强泛化，应联合谱峰纯度、二电平聚类和中间样本比例，而不能只看单个谱峰。
6. 频率路中的比较器毛刺可能影响FM/FSK/PSK边界，需要按实际板上数据继续标定。
7. 当前DAC输出是算法拟合或重建结果，不能等同于原始模拟解调链的逐点真实输出。

## 8. 经验总结

### 8.1 有效的设计决策

- 用包络与边沿时间两条通道分别获取幅度、频率和相位信息；
- 让ADC采集低频包络，而不是强行高速采样2MHz载波；
- 使用TIM8输入捕获DMA测量载波边沿；
- 采用固定40ms窗口统一两路采集；
- 使用百分位数代替绝对极值；
- 根据题目离散候选使用Goertzel而不是完整FFT；
- 保存原始捕获间隔统计，不把所有异常都丢弃；
- 用串口输出`cap/env/freq/result`分层诊断信息；
- 先修硬件链路，再调整分类阈值；
- AM参数采用多点标定和多次平均。

### 8.2 最重要的调试方法

本项目最有效的调试顺序是：

```text
先看模拟波形
→ 再看MCU引脚波形
→ 再看DMA数量
→ 再看基础统计
→ 再看分类特征
→ 最后才改阈值和标定
```

如果`cap=0`，首先检查TLV3501输出和PC6，不应先改FM阈值。

如果`env`只有稳定偏置，首先检查BAT54、RC、抬升和PB1，不应先改Goertzel。

如果类型正确但参数错误，再检查计算公式、候选频率和标定曲线。

这种分层方法避免了用软件阈值掩盖硬件链路问题。

### 8.3 可复用与不可复用内容

可以复用：

- 双通道总体架构；
- 固定窗口双DMA采集方法；
- 捕获值转瞬时频率的方法；
- 百分位稳健统计；
- 候选频率Goertzel；
- AM与ASK的多特征判决思路；
- 分层诊断和逐级示波器定位方法。

不可直接复用：

- AD603控制电压；
- `ENV_BIAS_ADC`；
- `ENV_RIPPLE_TH`、`ENV_TONE_TH`；
- ASK有效频率点数阈值；
- 比较器异常间隔阈值；
- AM `raw → m_a`分段系数；
- 具体RC时间常数和DAC输出滤波参数。

## 9. 后续若继续完善的建议

若后续继续进行完整验收，建议保持现有架构，重点补测试而不是立即重构：

1. 建立六类信号的统一测试矩阵；
2. 每个参数点至少重复10次；
3. 同时保存示波器截图和`capture/envspec/freq/result`日志；
4. 统计分类正确率、参数最大误差和重复性；
5. 对AM/ASK、FM/FSK、CW/低调制度AM三个边界单独做混淆测试；
6. 更换增益或硬件后重新标定，不沿用旧阈值；
7. 在完整数据集形成前，不把探索性结果写成稳定验证结论。
