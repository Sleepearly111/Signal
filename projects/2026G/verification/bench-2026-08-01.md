# 2026G 周期信号测量分析装置 - 每小问五组测试结果

测试时间：2026-08-01 16:27（北京时间）  
信号源：SIGLENT SDG2082X，CH1，50 Ω 负载，LAN 自动控制  
测量链：AD9248 INA 单通道 -> FPGA 2 MSPS / 4096 点 -> STM32  
统计方法：每个测试取 20 个完整有效窗口的中位数；全部分量初相位为 0°。  
频域幅值单位：mVpk（题目规定的“各分量幅值”，不是 Vpp）。

理论计算：

- 总真有效值：`Urms = sqrt(sum(Vpp_i^2 / 8))`。
- 总峰峰值：对所有 0° 基波/谐波的合成波形高密度重构后取 `max-min`，不能直接把各分量 Vpp 相加。
- 第3问的干扰为 200 mVpp，只叠加到装置输入，不计入被测信号 `ub` 的理论 Upp、Urms 和频谱幅值。
- 判定门限：`|Upp误差| <= 5 mV`、`|Urms误差| <= 5 mV`、`|基频误差| <= 1 kHz`、`|各分量幅值误差| <= 5 mV`、首个有效结果 `<= 2 s`。
