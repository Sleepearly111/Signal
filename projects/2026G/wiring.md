# 2026G 接线与器件

## 器件和接口

| 环节 | 器件或模块 | 核对点 |
| --- | --- | --- |
| 信号源 | 台架记录使用双通道任意波形源 | 核对幅值是对 50 Ω 还是 High-Z 定义。记录干扰单频的实际加入方式 |
| 模拟输入 | AD9248 模块 INA、板载 AD8132 | 模块输入网络与接收端端接需现场核对。INB 不参与最终计算 |
| 高速数字前端 | Cyclone IV E EP4CE10F17C8 | 采集、滤波、冻结窗口、应答。换板后核对 FPGA 管脚和 IO 电平 |
| 主控 | STM32F407 | SPI3 主机、连接中断和片选、计算结果 |
| 显示 | TJC 串口屏 | USART1 TX/RX 交叉连接且共地。确认屏端逻辑电平和供电要求 |
| 调试 | 串口工具、ST-Link、示波器 | USART2 用于诊断。SWD 烧录与串口分开接 |

## STM32 引脚

以下引脚来自收官工程和其 CubeMX 配置。FPGA 端按对应位流的网名接线，连接器脚位须对照板卡图。

| STM32 | 对端信号 | 方向（相对 STM32） |
| --- | --- | --- |
| PC10 / SPI3 SCK | FPGA SCLK | 出 |
| PC11 / SPI3 MISO | FPGA MISO | 入 |
| PC12 / SPI3 MOSI | FPGA MOSI | 出 |
| PB0 | FPGA CS_N | 出，低有效 |
| PD6 | FPGA DRDY | 入，上升沿 EXTI，配置下拉 |
| PA9 / USART1 TX | 屏 RX | 出 |
| PA10 / USART1 RX | 屏 TX | 入 |
| PA2 / USART2 TX、PA3 / USART2 RX | 调试 UART RX、TX | 交叉 |
| GND | FPGA、ADC 与串口信号参考地 | 共地 |

协议以 37 包传一个窗口，36 包各 112 点，尾包 64 点。样本为有符号 16 位小端，14 个有效位。A1 读取、A2 确认和 CRC16/CCITT-FALSE 用于可靠传输。SPI3 在 42 MHz 外设时钟和 64 分频配置下为 656.25 kbit/s。ADC 原始码型、模块满量程、板载增益和模拟输入端接需按实物核对。

## 起板顺序

1. 核对供电、端接、FPGA IO 和共地，先用已知小幅单正弦进入 INA。
2. 核对 DRDY、SPI、CRC 和 4096 点有效窗口。确认 2 MSPS、单路 A 和匹配的滤波配置。
3. 在固定线缆与幅值模式下重新标定。然后验证单音、谐波、多频叠加及干扰。
4. 手动检查串口屏的周期显示、频谱和数值单位。

STM32 侧保留应用代码和可查阅的配置。生成板级代码需安装 STM32CubeMX 与相应的 STM32CubeF4 / CMSIS-DSP。固件和 FPGA 位流的精确配对尚需归档，不应直接以现有源码快照承诺整机可烧录复现。
