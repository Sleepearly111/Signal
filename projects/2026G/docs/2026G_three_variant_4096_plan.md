# 2026G 方案演进

| 版本 | 模拟链与用途 | 结论 |
| --- | --- | --- |
| AD9280 通信保底 | 8 位 ADC → FPGA → STM32 | 建立协议、CRC、ACK 和 4096 点窗口基线 |
| AD9248 单路直连 | 同轴线 → 模块 INA → 板载 AD8132 → AD9248 A 路 | 最终方案。只保留一套通道校准 |
| AD9248 双路 THS4001 | A 路看输入，B 路看放大输出 | 通道负载、增益频响和两路标定增加了不确定度 |
| AD8421 单路增益 | 增益板到 ADC | 增益可能改善小信号码值，大信号动态范围和削顶须另测 |
| AD637 与 ADS8688 | RMS 转直流再读取 | 能补测综合有效值，频谱与各分量幅值仍需采样链 |

封箱配置和台架证据见[项目主页](../README.md)。AD9280 与 AD9248 不共享硬件验证结论。
