# 2023 H · 信号分离装置与锁相实验

[历届试题](https://nuedc.org/problems/#2023) · [test0 应用源码](source/) · [PLL 实验代码](pll-lab/)

## 接线与使用器件

| 模块 | 连接 |
| --- | --- |
| AD9833-A | PB12 FSYNC、PB13 SCLK、PB15 SDATA。DDS A 用作参考信号 |
| AD9833-B | PD12 FSYNC、PD13 SCLK、PD15 SDATA。DDS B 用于另一输出或重构路径 |
| AD630 鉴相板 | 待测参考和 DDS 输出经各自调理后送鉴相输入。鉴相输出经低通送 ADS8688 |
| ADS8688 | test0 调试记录中使用 CH0/CH1。与 STM32 软件 SPI 接口为 PD2–PD5 |
| 串口 | USART1 命令，USART2 诊断状态。在 `source/test0.ioc` 核对复用与端口 |

AD9833 代码中的参考频率对应样机的 10 MHz 模块时钟。切换为 25 MHz 版本时先更新频率字计算所用的实际时钟。

## 调试路线

1. 先单独扫相，检验 AD630 低通输出随相位呈余弦变化。记录中心、振幅和漂移。
2. 先缩小频差，再用相位采集选择适当的目标区间。频差尚存时，单点鉴相电压会随时间变化。
3. 在闭环状态记录误差、DDS 控制量和输出波形。持续观测与重启复测分别记录。

test0 来源工程 `e61a036` 保留了历史整题完成记录。之后的 PLL 专项保存过相位扫点、FLL 锁定、相位捕获和约 60 s 跟踪样本。专项结果的范围是对应通道与测试条件。

应用层快照须配合对应板级工程。部分旧工程引用上游加窗实现，复原工程时请按其来源和许可取得对应实现。
