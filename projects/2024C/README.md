# 2024 C · 无线传输信号模拟系统

## 低频模型

工程采用 STM32F407 双 DAC 和定时器触发 DMA。一路表示直达信号 SD，另一路通过数字模型生成带衰减、相移和时延的 SM。两路经过独立调理后用等值电阻无源合路。这个设计适合在低频观察相位、时延和叠加关系。

| 器件 | 连接和用途 |
| --- | --- |
| STM32F407 | PA4 / DAC CH1、PA5 / DAC CH2，明确代码中 SD/SM 的通道分配 |
| 每路低通 | 设计记录为 10 kΩ 与 220 pF。单级计算截止频率约 72.3 kHz，接入下游后的响应需测量 |
| 隔直与合路 | 设计记录为每路 0.1 µF 隔直，两个 10 kΩ 等值电阻汇到 SOut |
| TJC 串口屏 | USART1，项目总结记录为 115200，按 `source/app.ioc` 和屏工程核对信号方向 |

代码从 `source/User/` 进入，可先读滤波补偿、相位和双 DAC 的实现。低频换算应先说明保持时延还是保持相位差，二者满足 Δφ = −2πfτ。

项目总结记录了 30–40 kHz 模型测试，较早资产索引将工程登记为未连接硬件的原型。两份记录的基线与板卡对应尚未闭合，公开版本把这些结果保留为设计与历史记录。射频赛题范围须单独验证。

应用层快照须配合对应板级工程。部分旧工程引用上游加窗实现，复原工程时请按其来源和许可取得对应实现。
