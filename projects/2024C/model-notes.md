# 2024C项目总结

## 1. 项目简介

**题目**：无线传输信号模拟系统（2024 电赛 C 题）

**目标**：模拟电磁波直达信号（SD）和多径反射信号（SM），以及两者的合成输出（SOut）。所有参数通过数字域精确控制。

**核心思路**：原题 30~40MHz 载波缩放到 30~40kHz 低频等效——利用 STM32F407 内部 DAC 直接生成，无需高频 DDS 芯片。信号模型、公式、参数控制完全等效，验证成本极低。

**实现方案**：STM32F407 双通道 DAC（PA4/PA5）→ TIM6 TRGO 1Msps DMA 同步输出 → 二阶 RC 低通 → 隔直 → 测试端口。两路信号通过 10kΩ+10kΩ 电阻合路输出 SOut。

                         │        STM32F407 @ 168MHz        │
                         │                                  │
   参数输入 ──────────→  │  radio_signal_app.c (应用层)      │

                         │    ↓         ↓                   │
                         │  SD计算    SM计算                │
                         │    ↓         ↓                   │
                         │  buf_SD    buf_SM (1000点×2)     │
                         │    ↓         ↓                   │
                         │  DMA1_S5   DMA1_S6 (循环)        │
                         │    ↓         ↓                   │
                         │  DAC1(PA4) DAC2(PA5)             │
                         │    ↑                             │
                         │  TIM6 TRGO @ 1MHz 同步触发        │

                                          │
                    ┌─────────────────────┼─────────────────────┐

              │ 10k+220p │        │ 10k+220p │  二阶RC低通       │
              │   fc≈72k │        │   fc≈72k │                  │
              └────┬─────┘        └────┬─────┘                  │

| 项目 | 值 |
|------|-----|
| MCU | STM32F407VGTx |
| 系统时钟 | 168MHz (HSE 8MHz → PLL) |

**信号模型**（`dual_channel.c`）：

- SD[n] = Ac × [1 + m×sin(2π×fm×n/fs)] × sin(2π×fc×n/fs)
- SM[n] = α×Ac × [1 + m×sin(2π×fm×(n/fs−τ))] × sin(2π×fc×(n/fs−τ) + φ)

## 6. 调试问题记录

### STM32F4 HAL DAC_TRIGGER_T6_TRGO Bug

**现象**：DAC 输出恒定 0.072V，DAC_CR TEN 位未置。

**原因**：`DAC_TRIGGER_T6_TRGO = 0x00`，与 `DAC_TRIGGER_NONE` 同值，HAL 误判不设 TEN 位。

**解决**：`dac.c` 中手动 `SET_BIT(hdac.Instance->CR, DAC_CR_TEN1 | DAC_CR_TEN2)`。

### TIM6 ARR=0 锁死

**现象**：TIM6 CNT 始终为 0，无 TRGO，DAC DHR→DOR 不传输。

**原因**：STM32F4 TIM6 ARR=0 锁定计数器。

**解决**：ARR=1, PSC=41 → 84MHz/42/2=1MHz。

### RC 低通负载过重

**现象**：DAC 管脚 3Vpp，滤波后 1.5Vpp，衰减 50%。

**原因**：原 1kΩ+1nF/2.2nF 负载过低（<5kΩ），DAC 缓冲器驱动不足；后改为 10kΩ+220pF，220pF 容性负载（>50pF 上限）仍有衰减。

**解决**：软件频率补偿表 + 后续标定。

### USART1 旧代码冲突

**现象**：串口屏只显示 READY，不响应 Apply。

**原因**：`stm32f4xx_it.c` 遗留 `USART1_IRQ_User_Handler()` 在 HAL 前读走 RXNE 字节，`tjc_hmi.c` 的 `HAL_UART_RxCpltCallback` 永远收不到数据。

**解决**：删除旧 USART1 中断处理代码。

### 相位 180° 误解

**现象**：RST 后两通道反相（Δφ=180°），误认为 bug。

**原因**：τ=50μs 在 30kHz 下载波相位偏移 540°≡180°，加上 φ=0° = 180°。这是物理正确的——τ 天然产生载波相位偏移。

**解决**：调试输出同时显示 τ 贡献和总 Δφ。
