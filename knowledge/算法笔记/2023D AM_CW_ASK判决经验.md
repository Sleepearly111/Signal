# 2023D AM、CW与2ASK判决经验

## 来源项目

- 项目：`projects/AI生成项目/2023D/`
- 来源提交：`7b15a787b626726fd7fbfba4b5f12c057ad56c1b`
- 来源数据：包络ADC固定窗口、候选频率Goertzel结果、输入捕获有效点数及长间隔统计
- 已验证范围：CW/AM分类闭环，AM 1 kHz和5 kHz板上测试，ma板级标定及多次平均
- 限制：2ASK仅有部分6/8/10 kbps调试记录，尚无完整码型、幅度、码率和重复性矩阵

本文总结判决思路和误判边界，不保存2023D阈值、候选表或分类源码。

## 背景

CW、低调制度AM和2ASK都可能在包络通道表现为“变化不大”或“存在幅度变化”。只使用包络峰峰值会把低调制度AM判成CW；只使用有效载波边沿数量又会把高调制度AM判成2ASK。

2023D最终采用包络单音、包络分布和边沿连续性联合判断，并把判决顺序本身作为分类模型的一部分。

## 核心经验

### 1. CW与低调制度AM不能只看包络起伏

实际CW包络并非完全平直，AD603噪声、BAT54纹波、RC残留和ADC噪声都会产生非零起伏。低调制度AM的幅度变化可能与这些起伏接近。

两者的重要差别是：

- CW的小起伏通常缺少稳定、集中的调制频率；
- AM即使幅度较小，仍应在合法调制频率附近形成重复性较好的单音响应。

因此峰峰值或分位差适合做初筛，不能独立完成CW/低调制度AM最终判决。

### 2. Goertzel适合离散候选频率

题目调制频率来自少量已知候选时，可以对去均值后的包络序列逐个计算Goertzel响应：

```text
包络ADC
→ 去直流/归一化
→ 对候选频率逐一计算响应
→ 选择最大响应
→ 检查幅度、纯度与重复性
```

Goertzel的优势是只计算需要的频点；它不是连续频率估计器。候选集合、采样率、窗口长度和归一化方法改变后，响应门限必须重新建立。

除最大响应外，还应关注：

- 最大响应相对CW噪声底的裕量；
- 最大频点与次大频点的比值；
- 多次窗口的频点一致性；
- 非整周期、频偏和周期性ASK码型产生的谱线。

### 3. AM应在ASK点数捷径之前判决

高调制度AM谷底可能让比较器暂时没有越过门限，导致有效捕获点减少和长间隔增加。这与2ASK低电平码元期间断载波的表现相似。

若先执行“有效频率点少 → ASK”，高调制度AM会被过早截走。更稳健的顺序是：

```text
先检查包络是否存在合法且稳定的AM单音
    ↓ 否
再检查包络二电平、边沿缺失和长间隔等ASK特征
```

这不是简单把AM阈值调低，而是让更具物理特异性的特征先获得解释权。

### 4. 高调制度AM与2ASK必须联合多特征

高调制度AM通常具有连续周期包络；2ASK更接近高低两种幅度状态，但真实RC会让跳变变钝。建议联合：

- 候选频率单音强度和谱峰纯度；
- 包络样本是否集中成两个电平；
- 中间幅度样本比例；
- 有效载波频率点数量；
- 长捕获间隔数量和分布；
- 多个窗口结果的一致性。

任何单一特征都存在反例：

- 高调制度AM会丢边沿；
- 固定周期2ASK码型也可能产生强单音；
- RC过大时2ASK具有大量中间样本；
- 噪声和削顶会破坏AM谱峰。

### 5. 误判应按物理链路定位

推荐调试顺序：

```text
包络模拟波形
→ ADC偏置与量程
→ 包络分位数和归一化
→ Goertzel各候选响应
→ 捕获点数及长间隔
→ 二电平统计
→ 最后调整判决顺序和门限
```

如果包络链本身不稳定，继续调整分类阈值只能把硬件问题固化成板级常数。

### 6. 阈值和标定数据属于当前测量链

CW噪声底、AM单音门限、ASK点数门限和二电平比例都会受到AD603增益、比较门限、BAT54、RC、偏置、ADC参考和窗口长度影响。可复用的是特征组合和判决顺序，不是2023D的数值。

## 适用范围

- 同时具备包络通道和载波边沿通道的CW/AM/OOK或2ASK识别；
- 调制频率来自少量离散候选的嵌入式识别；
- 需要解释低调制度与高调制度边界误判的工程调试；
- 可接受按物理特征分层、而非单个统一阈值的分类系统。

## 不适用范围

- 不适用于任意连续调制频率的精确估计；
- 不保证随机、周期、长连0/1等全部2ASK码型均可可靠区分；
- 不适用于只有单一包络通道且完全没有边沿或相位信息的所有情况；
- 不提供CW、AM或ASK的通用数值门限；
- 不把2023D部分ASK调试结果表述为整类完整验收。

## 失败案例

1. 只用`env_ripple`：阈值高时低调制度AM判成CW，阈值低时CW噪声又判成AM。
2. 先用有效频率点数判断ASK：60%以上AM谷底造成边沿减少，曾被判成2ASK。
3. 把最大Goertzel频点直接当作AM：周期性2ASK码型也可能形成明显包络谱线。
4. 包络链噪声或失真较大时，真实1 kHz可能选择到其他候选频点；问题根源可能是模拟信噪比和归一化，而不是采样点数不足。
5. 改变AD603增益或ADC偏置后继续沿用旧门限，使已经调好的CW/AM边界再次失效。

## 后续建议

- 建立CW、低调制度AM、高调制度AM和多种2ASK码型的混淆矩阵；
- 每个条件重复多窗口，记录误判率而不是只保存一次成功日志；
- 增加谱峰纯度、二电平聚类和中间样本比例的联合评估；
- 分别测试随机码、固定周期码和长连0/1，明确不可判定区域；
- 对改变增益、偏置、RC和板卡后的门限迁移做回归；
- 若信号证据冲突，允许返回“不确定”而不是强制吸附到AM或ASK。
