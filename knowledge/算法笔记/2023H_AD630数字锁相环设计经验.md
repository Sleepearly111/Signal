## 1. 完整系统模型

### 1.1 模拟-数字混合 PLL 架构

```text
模拟域                              数字域
───────                            ──────

AD630 鉴相器                       phase_error
  │  Vout = offset + K·cos(Δφ)        │
  │  输入: A 与 A' 的相位差            │
  │  输出: mean_mv (直流电压)          ▼
  ▼                              Loop Filter
ADS8688 ADC                      ┌─ P 项 (比例)
  │  code = (V - 32768)/32768    │─ I 项 (积分, 抗饱和)
  │       × 5120                 │─ 限幅 (±1365 steps)
  ▼                              │─ 死区
PLLPhase_UpdateWindow()          └─→ phase_increment
  │                                    │
  │  phase_offset                      ▼
  │                              AD9833 PHASE0
  └─────────────────────────────→ register (0-4095)
                                      │
                                      ▼
                                 A' 输出相位改变
                                      │
                                      ▼
                                 Δφ 变化 → 闭环
```

**为什么数字域可以控制模拟鉴相器输出**：
- AD9833 的 PHASE0 寄存器（12-bit, 0-4095 → 0°-360°）改变的是 A' 的**瞬时相位**
- A' 相位改变 → Δφ 改变 → AD630 的 `mean_mv = offset + K·cos(Δφ)` 改变
- STM32 写入一个数字 → DDS 输出相位偏移 → 模拟鉴相器电压改变 → ADC 读到新值
- 这是真正的数字-模拟混合闭环，不需要 DAC 或模拟环路滤波器

### 1.2 模拟鉴相器接入数字 PLL 的关键约束

```text
Vout_DC = offset + K · cos(Δφ)
```

1. **输出是相位差的余弦函数，不是线性函数**。只有在 ±90°（正交零点）附近才近似线性。
2. **存在未知 DC offset**，且会随温度、供电漂移。不能假设 offset 不变。
3. **无内置极性判断**。cos(Δφ) = cos(-Δφ)，正负相位误差给出相同的电压。单点测量无法判断方向。
4. **响应带宽受限**。AD630 输出经过 LPF（片上/外部），相位突变后的稳定需要时间。

## 2. FLL 与 PLL 分工

### 2.1 分解原理

```text
            AD630 DC 输出
                  │
      ┌───────────┴───────────┐
      │                       │
    dV/dt                    V_dc
    ∝ Δf                    ∝ cos(Δφ)
      │                       │
      ▼                       ▼
    FLL                      PLL
  "不要转"                  "转到哪里"

FLL — 频率锁定环                PLL — 相位锁定环
─────────────────              ─────────────────
解决: 频率误差 Δf                 解决: 瞬时相位误差 Δφ
检测: phase 变化率               检测: mean_mv 绝对值
输入: filtered_slope_mv_s      输入: filtered_mean_mv
输出: freq_word_offset         输出: phase_word_offset
      + delay_flag                    (AD9833 PHASE0)
```

### 2.2 为什么必须两个环同时运行

```
d(Vout_DC)/dt = -K·sin(Δφ) · Δω

slope 包含两项:
  sin(Δφ) — 与当前相位有关 (PLL 的范畴)
  Δω      — 与频率误差有关 (FLL 的范畴)

当 Δφ 不在 0° 或 180° 时 (sin ≠ 0):
  slope ≠ 0 ⇔ Δω ≠ 0  → slope → 0 即可判断频率匹配

当频率匹配 (Δω ≈ 0) 时:
  mean_mv 的绝对值直接反映 Δφ → PLL 可以独立工作
```

**两个环观察同一物理信号的不同维度**——时域均值 vs 时域变化率——从而实现正交控制，不会互相打架。

| 策略 | 问题 |
|------|------|
| 只跑 FLL | 频率锁定后相位自由漂移，示波器波形左右移动 |
| 只跑 PLL | 残余频差持续累积，PLL 输出饱和后相位跳变 |
| **FLL + PLL 同时** | FLL 持续消除 Δf，PLL 持续消除 Δφ，互相不干扰 |

## 3. Phase Acquisition — 捕获与跟踪分离

### 3.1 为什么传统 PLL 启动慢

**根源**：cos(Δφ) 在不同区间的行为完全不同。

```text
Δφ ≈ ±90°: dV/dφ = |K| (最大) → PI 有响应, 但 |V| ≈ 0 (信噪比最低)
Δφ ≈ 0°:   dV/dφ = 0        → PI 无响应 (增益为零, "失明")
Δφ ≈ 180°: dV/dφ = 0        → PI 无响应 (增益为零)
```

传统 PI 型 PLL 只能**局部收敛**——如果初始相位恰好靠近 0° 或 180° 的"死区"，PI 看不到误差方向，可能永远无法锁定。需要**全局搜索**来找到一个好的起点。

### 3.2 Capture + Track 结构

```text
          FLL LOCKED
              │
  ┌───────────┴───────────┐
  │                       │
Phase Acquisition     Phase Track
(一次，启动时)         (持续，运行时)
  │                       │
phase sweep             ±1 step P&O
全范围搜索              局部维护
  │                       │
找到全局最优            维持局部最优
  │                       │
直接写 phase_offset     微调 phase_offset

Capture: 可接受较长耗时 (秒级), 需要扫描全范围
Track:   必须轻量无感, 不能频繁跳变, 每次只动 0.088°
```

### 3.3 Capture 流程

```text
1. 等间隔扫描 N 个相位角度 (建议 4-8)
2. 记录每个角度的 AD630 直流输出
3. argmax(mean_mv) → best_angle (cos 最大 = 最接近同相)
4. 检查 span = max-min ≥ 阈值 (保证 AD630 信号有效)
5. 一次性写入 best_phase
6. 进入 Track
```

**捕获参数建议**：

| 参数 | 建议范围 | 理由 |
|------|---------|------|
| 扫描点数 | 4-8 | 余弦极值少，平滑，4 点一般够 |
| 每点耗时 | 10-200ms | 无 LPF 时极短；有 LPF 需等稳定 |
| 最佳点判据 | max(mean_mv) | 同相锁定；用 min 则是反相 |
| span 阈值 | ≥30mV | 保证余弦响应有效 |

**无扰动扫描**：如果 DDS 支持双相位寄存器（如 AD9833 的 PHASE0+PHASE1+PSEL），可以用"影子寄存器"实现每点仅 ~8ms 的测量窗口，避免示波器可见的相位跳变。

### 3.4 Track — 扰动-观察 (P&O) 而非 PI

**为什么不用 PI**：
- 在 cos 峰值附近（锁定点），dV/dφ ≈ 0 → PI 增益为零
- 在 cos 线性区，增益大 → 容易振荡
- 单一 PI 增益无法覆盖 cos 全范围

**为什么用 P&O（扰动-观察）**：
- 不需要线性假设：只比较扰动前后的 `mean_mv` 大小
- 步长固定（1 step = 0.088°），示波器不可见
- 间隔足够长（5-10 窗 = 1-2 秒），避免噪声误导
- 适合"已经接近最优点，只需要微调"的场景

## 4. 失败方案复盘（可复用教训）

### 4.1 固定 target_mv PI

**做法**：`v_target_mv = 锁定瞬间的 mean_mv`，之后 PI 维持。

**为什么失败**：
- target 随启动位置变化 → 每次 K0 后 target 不同 → 无法复用参数
- AD630 offset 温漂 → target 10 分钟后失效
- PI 积分器在 cos 非线性区容易饱和

**教训**：**不要用绝对电压作为锁相目标**。锁相目标应通过 Phase Acquisition 在每次启动时重新确定。

### 4.2 Hill Climbing

**做法**：每窗 ±1 step，选 `mean_mv` 更高的方向。

**为什么失败**：
- 梯度搜索速度无法追踪残余频差（漂移速度 > 搜索速度）
- ±1 来回震荡：噪声导致相邻窗比较不可靠
- 收敛极慢：0.088°/step, 45° 需要 512 步 ≈ 100 秒

**教训**：**Hill climbing 适合无频差的静态微调，不适合有残余频差时的初始捕获**。初始相位获取必须用全扫描，不能用逐步爬山。

### 4.3 FLL 冻结

**做法**：FLL 锁定后冻结 `freq_word_offset`，只跑 PLL。

**为什么失败**：
- 瞬时频率微差在相位域持续累积
- 相位 PI 没有足够带宽补偿频率误差
- 最终 `phase_offset` 饱和 → 跳相

**教训**：**FLL 和 PLL 必须同时运行**，不可冻结任何一个。FLL 持续消除残余频差，PLL 只处理残余相位偏移。

### 4.4 center_mv 的定位

**发现**：`phase_sweep` 确认 `center_mv ≈ -62mV`（cos 的正交过零点），鉴相灵敏度最高。

**适合用途**：
- 判断 AD630 工作正常（有清晰的余弦响应）
- FLL 锁定的辅助参考（漂移方向判断）
- `ad630 zero` 命令标定

**不适合用途**：
- 作为 PLL 锁定目标（正交点 |V| 最小，信噪比最低）
- 跨启动/长时间复用（offset 漂移）

**教训**：**center_mv 是调试工具，不是控制目标**。

## 6. 调试方法论

### 2.1 先鉴相，再锁相

验证顺序：
1. `phase_sweep` → 确认 AD9833 相位寄存器有效，AD630 输出余弦响应
2. `phase_cal_test` → 确认余弦 span/center 可重复
3. FLL SEARCH → 确认频率可以锁定
4. Phase Acquisition → 确认可以找到最佳相位
5. Phase Track → 确认长期保持

### 2.2 示波器是最重要的调试工具

串口数据（mean_mv, slope_mv_s, offset）是间接信号，示波器探头直接看 A 和 A' 是最终判断标准。

**判据**：
- 两路波形同频 = FLL 成功
- 两路波形不再左右漂移 = PLL 成功
- A' 出现 0°/45°/90° 跳变 = Phase Acquisition 正在运行

### 2.3 关键故障模式

| 现象 | 原因 | 检查 |
|------|------|------|
| ADC 饱和 (mean=5120) | AD630 信号丢失 | 信号源是否开启、接线是否断开 |
| FLL 锁定但持续漂移 | 无 PLL 或 PLL 步长太小 | 确认 ENABLE_PHASE_LOOP=1、步长≥1 |
| Capture 后相位大跳 | phase_word_offset 基址错误 | 确认 TRACK 写入 = best_pha + offset |
| 两环互相打架 | FLL/PLL 共用 mean_mv | FLL 只读 slope, PLL 只读 mean |
| COUPLE 只显示 CH1 | 共享计数器被重置 | 改为 per-channel 计数器 |

## 5. 参数设计指南

### 3.1 FLL 参数

| 参数 | 建议范围 | 说明 |
|------|---------|------|
| 锁定阈值 RMS | 5-15 mV | 取决于 AD630 输出噪声 |
| 锁定阈值 slope | 50-150 mV/s | 太严格→锁不住，太宽松→假锁 |
| 确认次数 | 3 | 太少→假锁，太多→锁定太慢 |
| 修正步长 (SEARCH) | 4 units | 快速趋近 |
| 修正步长 (HOLD) | 1 unit | 最小有效步长 |
| 冷却窗口 | 2-3 | 给测量留反应时间 |
| freq_offset 限幅 | ±32 | 太小→搜索范围不够，太大→不稳定 |
| delay_flag 范围 | 0-16 | dithering 分数频率分辨率 |

### 3.2 PLL 参数

| 参数 | 建议范围 | 说明 |
|------|---------|------|
| 扫描点数 | 4-8 | 余弦极值很少，4 点一般够用 |
| 每点窗口数 | 1-2 | 无 LPF 时 1 窗 (200ms) 够用 |
| Track 步长 | 1 (0.088°) | 最小步长，示波器不可见 |
| Track 间隔 | 5-10 窗 | 1-2 秒一次即可，不需要频繁 |
| Phase 限幅 | ±120° | 防止方向错误时跑远 |

### 3.3 1 unit 等效频率

```text
FCLK = 10 MHz
1 freq_word = FCLK / 2^28 = 10,000,000 / 268,435,456 ≈ 0.03725 Hz

1 unit (dither) = 1/16 freq_word ≈ 0.00233 Hz

在 10 kHz 输出频率下:
1 unit = 0.00233 / 10000 = 0.233 ppm
```

## 7. 硬件边界

### 4.1 AD630 使用要点

- 输入信号幅度不能太小（<50mVpp 会导致 DC 输出淹没在噪声中）
- 输出端 RC 低通滤波器合适截止频率 = 信号频率的 1/10 ~ 1/100
- 无 LPF 时 AD630 输出包含强交流分量，需要多采样点取平均
- AD630 两路输出（OUT1, OUT2）各自独立，可同时用于两路鉴相

### 4.2 AD9833 注意事项

- PHASE0 寄存器可直接写入，不影响频率输出
- PSEL 位可软件切换 PHASE0/PHASE1，PHASE1 可作"影子寄存器"实现无扰动扫描
- `wave_flag` 全局变量在多通道操作时必须保存/恢复
- 10 MHz 板载晶振，误差 ±20ppm（典型值）

### 4.3 ADS8688 使用要点

- AUTO_RST 模式在每轮采样前需复位序列
- `ads8688_fault` 必须检查，fault 时跳过本轮测量
- CH0/CH1 的语义与板上丝印严格对齐，不可互换

## 8. 适用边界

### 5.1 可直接复用此经验的场景

- AD630 或其他模拟乘法器（MC1496, AD633 等）作为鉴相器
- 外置 DDS（AD9833/AD9834/AD9850 等）提供本地参考
- STM32 或同等算力的 MCU 控制

### 5.2 不能直接套用的场景

- 全数字 PLL（无模拟鉴相器，用 ADC 采样+数字乘法）
- 高频 (>1MHz) PLL（AD630 带宽限制，需换鉴相器）
- 需要跟踪变化的相位差的场景（此方案锁定后相位固定）
- 无独立相位控制寄存器的 DDS（需改用 NCO 方案）

### 5.3 风险提示

- Phase Acquisition 扫描期间输出相位会发生变化（除非使用 PHASE1 影子寄存器或硬件 mute）
- AD630 offset 漂移不可完全消除，长期（>10min）运行可能需要重新校准
- 两个 AD630 通道之间的串扰未在本项目中定量测试
