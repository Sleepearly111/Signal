# K-DSP-005：2025G AD630 拍频 FLL 与软件 DDS 稳频经验

> 来源项目：`projects/已完成项目/2025G/2025G/`  
> 来源文件：`Src/ad630_fll.c`、`Src/adva_replay.c`、`Core/Src/main.c`  
> 调试总结：`docs/2025G_发挥2_FLL_DDS_调试总结.md`  
> 最后核对：2026-07-27  
> 验证边界：L3（来源板卡、接线、固件和用户实测条件内）

## 1. 解决的问题

2025G 发挥(2) 只要求装置输出与未知电路输出同频稳定显示，不要求固定相位。因此最终采用 FLL，而不是把 AD630 直流相位误差闭合为 PLL：

```text
装置输出 ─┐
          ├─ AD630 模拟鉴相/混频 ─ ADS8688 ─ 拍频估计 ─ FLL
未知输出 ─┘                                      │
                                                ▼
固定采样率软件 DDS ← 32 位相位步进微调 ← trim
```

来源项目在用户确认的 1–50 kHz、正弦/三角/矩形输出范围内改善了相对漂移；整理后的固件也完成了 8 kHz 矩形和 40 kHz 回归。该结论只属于来源整机，不代表任意 AD630 电路、负载或新控制器天然有效。

## 2. 可复用的方法

### 2.1 先确认模拟链路，再调控制器

AD630 输出只有在两路输入、偏置、幅度和隔直链路正常时才有可解释性。来源调试中隔直故障曾造成 A/B 路异常和“AD630 输出不变”的假象。应先在 AD630 A、B 输入逐点确认波形，再观察 OUT 的慢包络或拍频，而不是先改闭环参数。

### 2.2 只用新鲜拍频推进 FLL

低拍频意味着一个有效周期可能需要数秒。控制服务调用频率不能冒充测量更新率：

- 拍频周期必须用真实时间差换算；
- 没有形成新周期时，观测标为 stale；
- stale 数据不累计锁定/解锁计数，也不触发 P&O 反向；
- 连续新鲜观测满足锁定门限后才进入 HOLD。

这能避免旧数据被高频 Service 循环重复消费后产生连闪、误反向或瞬间锁定。

### 2.3 搜索使用粗细两级扰动观察

FLL 不从 AD630 的正负直接推断“哪边频率更高”，而是先施加一个小频率扰动，再观察拍频绝对值：

- 拍频下降：保持当前方向；
- 拍频上升且超过噪声裕量：反向；
- 大拍频用粗步进，小拍频用细步进；
- 反向需要裕量，避免噪声导致每次观测都翻转。

控制方向必须通过开环正负频差试验确认，不能根据软件变量名猜测。

### 2.4 HOLD 应冻结执行器并带解锁滞回

题目不要求相位，因此进入锁定区后继续追逐 AD630 瞬时量会把噪声重新注入输出。HOLD 保留最后 trim，不再连续微调；只有多个新鲜观测超过更高的解锁门限才回到 SEARCH。

### 2.5 固定采样率软件 DDS 优于改 ARR

早期方案通过 TIM6 ARR 的 sigma-delta 微调平均频率，能获得小于单个定时器分频步距的分辨率，但会把周期抖动直接施加到 DAC 更新节拍。最终方案改为：

- TIM/DAC 更新率固定；
- 32 位相位累加器连续推进；
- FLL 只修改相位步进；
- DMA HT/TC 分半填充下一段波形；
- ISR 内不打印、不做阻塞操作。

这样频率分辨率由相位步进决定，采样时钟和输出缓冲保持连续，也能统一支持正弦、三角和矩形。

## 3. 调试顺序

1. 禁用闭环，执行 `0 → +5 Hz → -5 Hz → 0` 开环序列；
2. 用示波器确认两路相对漂移方向在正负偏差时反转；
3. 确认拍频估计在强制约 5 Hz 频差时接近 5 Hz；
4. 检查 FLL 只在 fresh 观测到达时改变方向或确认计数；
5. 打开 SEARCH，观察拍频总体下降；
6. 检查锁定确认、HOLD 冻结和解锁滞回；
7. 最后遍历 1–50 kHz 和全部要求波形，而不是只验证单一频点。

开环测试属于调试工具，完成控制方向和执行器验证后应默认关闭，避免按键启动后先经历人为 ±5 Hz 漂移。

## 4. 失败现象与判断

| 现象 | 优先检查 |
|---|---|
| AD630 OUT 长时间不变 | A/B 输入是否都真实到达、隔直和偏置是否正确、是否饱和 |
| 某些频率突然连续闪动 | stale 周期是否被重复消费、P&O 反向裕量是否小于噪声 |
| 频率越高漂移越快 | ARR 量化/抖动、DMA 连续性、每周期采样点和输出滤波 |
| 整体向一侧漂但偶尔反向闪 | 控制方向映射、测量延迟、旧观测与新动作是否错配 |
| 矩形波圆角或平台不平 | DAC 更新率、模拟带宽、负载和滤波；不能只靠 FLL 修复 |

## 5. 不可直接复用的项目参数

以下值只记录来源工程量级，不是 Framework 默认值：

- 锁定/解锁阈值约 `0.18 Hz / 0.35 Hz`；
- 粗/细调整量约 `0.5 Hz / 0.1 Hz`；
- 软件 DDS 更新率约 `1.2 MSPS`、32 位相位累加器；
- ADS8688 通道、AD630 幅度门、零点和偏置；
- 来源板的频率标定、晶振 ppm、DAC 幅度表和输出滤波；
- DMA 缓冲长度、TIM6 ARR、IRQ 优先级和 HAL 回调所有权。

新板必须重新测量实际时钟、执行器方向、拍频噪声、延迟、带宽、负载和全频段波形。

## 6. 适用与不适用

适用条件：

- 目标只要求同频，不要求固定相位；
- AD630 输出能形成可测的低频拍频信息；
- 执行器可以连续、单调地细调输出频率；
- 允许以慢于载波很多的速率收敛。

不适用：

- 题目要求相位误差、相干采样或固定相位关系；
- 拍频低到无法在总时间预算内得到新鲜周期；
- 输入间歇、严重失真或 AD630 长期饱和；
- 执行器调整会破坏波形或存在未建模的大死区。
