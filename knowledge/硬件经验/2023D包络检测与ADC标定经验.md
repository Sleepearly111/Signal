# 2023D包络检测与ADC标定经验

## 来源项目

- 项目：`projects/AI生成项目/2023D/`
- 来源提交：`7b15a787b626726fd7fbfba4b5f12c057ad56c1b`
- 来源链路：`AD603 → BAT54 → RC → ENV_RAW → 抬升 → ENV_ADC → STM32 ADC DMA`
- 验证边界：当前样机已观察到AM包络变化，并完成1 kHz、5 kHz调制频率检测和板级ma标定；具体偏置码、RC、阈值和标定表不具有跨板通用性

本文记录模拟包络链和软件坐标系的联合经验，不保存项目标定表或实现代码。

## 背景

2023D用BAT54和RC从2 MHz载波中提取低频包络，再把信号抬升到STM32单电源ADC可采范围。调试早期，软件把`ENV_BIAS_ADC`当作0，而硬件输出的ADC中位值实际不为0，导致包络归一化、AM/CW阈值和ma计算都失去正确坐标基准。

后续板上标定还表明，二极管压降、RC动态、AD603增益、偏置和负载会使理想AM公式与ADC统计量之间产生非线性。因此需要把“检波”“ADC坐标变换”和“物理量标定”作为一条完整测量链处理。

## 核心经验

### 1. BAT54与RC承担不同任务

BAT54用于高频整流，RC用于抑制2 MHz载波纹波并跟随低频包络。时间常数存在双重约束：

- 太小：残留载波和开关尖峰较多，CW也会出现非零包络起伏；
- 太大：最高调制频率被衰减，包络峰谷变钝，ASK边沿和ma都会失真。

设计时应使RC显著抑制载波，同时保留题目要求的最高包络频率。最终参数需在真实源阻抗、二极管、后级输入和探头负载下验证，不能只用孤立的理论截止频率判断。

### 2. `ENV_BIAS_ADC`是算法坐标原点

抬升后的ADC码值可以表示为：

```text
x_adc[n] = bias_adc + envelope_ac[n] + noise[n]
```

`ENV_BIAS_ADC`不是装饰性常量。它参与：

- 去直流或恢复以偏置为原点的交流量；
- 包络起伏归一化；
- CW与AM阈值；
- ma原始统计量计算；
- ADC上下量程裕量判断。

偏置设错后，即使波形在示波器上可见，软件得到的比例、阈值和标定仍可能全部偏离。偏置应来自当前采集链的稳态统计和专门标定，而不是假设为0或理想半量程。

### 3. 明确三种坐标系

建议在设计和日志中区分：

1. **ADC绝对码坐标**：包含硬件抬升，适合检查饱和、断线和工作点；
2. **去偏置坐标**：以实际直流工作点为零，适合波动和频谱分析；
3. **归一化/标定坐标**：相对某个稳健直流量或经板级曲线映射后的物理量，适合分类和ma估计。

不要在不同坐标系之间复用同一阈值。日志中的`raw`必须注明计算公式、去偏置方法、归一化分母和平均次数。

### 4. ma标定不能跨板复用

理想AM包络可用峰谷关系估算调制度，但实际链路还包含：

- BAT54正向压降及小信号非线性；
- RC对不同调制频率的幅度和相位影响；
- AD603增益、削顶和噪声底；
- 偏置网络、ADC参考、输入采样网络和负载；
- 器件批次、温度、供电和接线；
- 统计方式与多次平均。

因此2023D使用的`raw → ma`关系只属于当前板卡和测试条件。更换板卡、增益、RC、偏置、输入幅度、调制频率或负载后，应重新采集原始点并复核单调性。

### 5. 标定必须保存数据边界

至少记录：

- 板卡编号、硬件版本、飞线与器件批次；
- 输入载频、输入Vpp、真实ma、调制频率；
- AD603控制点和实测输入/输出幅度；
- BAT54、RC、偏置和ADC参考条件；
- 采样率、窗口长度、统计公式和平均次数；
- 每个标定点的原始统计量、重复测量分布和异常现象；
- 拟合或分段映射的有效区间；
- 是否存在非单调、削顶、谷底失真或噪声底。

若原始统计量随真实ma不再单调，不能通过强制分段映射伪造连续准确结果，应先修复模拟链或明确不可测区间。

### 6. 多次平均只改善随机波动

多次采集平均有助于减小触发相位、噪声和单窗口统计波动，但不能修复：

- 偏置设错；
- 二极管和RC造成的系统非线性；
- AD603或ADC削顶；
- 错误接线；
- 非单调标定；
- 分类逻辑选错信号类型。

平均前应先保证每次采集属于同一硬件状态和同一坐标系，并保留离群和方差指标。

## 适用范围

- 二极管+RC包络检测后接单电源ADC的测量链；
- AM包络、ASK幅度状态或低频幅度变化的采集；
- ADC偏置、归一化、分类阈值和板级物理量标定；
- 电赛中小信号检波链的快速校准与证据记录。

## 不适用范围

- 不适用于把当前BAT54压降、RC或`ENV_BIAS_ADC`当作其他板卡默认值；
- 不证明包络链在全部AM频率、调制度、ASK码型和温度范围内通过；
- 不替代精密同步检波、IQ解调或宽动态范围测量方案；
- 不保证理想峰谷公式在小信号、削顶或非单调区间成立；
- 不提供2023D的具体ma分段表。

## 失败案例

1. `ENV_BIAS_ADC`设为0，而实际ADC中位工作点明显非零，导致`env_ripple`尺度和ma原始量错误，AM分类与估计随之异常。
2. 改变AD603增益或硬件偏置后继续使用旧阈值和旧ma曲线，原先通过的AM点重新误判。
3. 仅依据理想AM公式计算ma，未补偿BAT54、RC和负载非线性，得到的ma与信号源设定值不一致。
4. 高调制度时包络谷底失真、比较器边沿减少，若把这个现象直接归类为ASK，会把模拟前端非线性混入调制分类。
5. RC或包络信噪比不合适时，真实1 kHz信号可能在候选频率扫描中被其他频点压过；这不是简单增加采样点就一定能解决的问题。

## 后续建议

- 为每块板保存“真实ma—原始统计量—重复性”表和完整测试条件；
- 以CW噪声底、低调制度AM和高调制度谷底分别建立边界测试；
- 在1 kHz、5 kHz及中间候选频率复核RC的频率依赖；
- 同时监测ADC绝对码的上下裕量，避免标定落在削顶区域；
- 若标定曲线非单调，优先调整增益、检波和偏置，不靠软件强制吸附；
- 复用既有《电赛标定记录规范》，避免只保存最终系数。
