# FPGA + AD9280 到 STM32 高速采样桥接经验

- Knowledge ID：`K-FPGA-001`
- 来源日期：2026-07-28
- 来源工程：`projects/已完成项目/FPGA_STM32高速采样桥/`
- 验证边界：指定 EP4CE10F17C8、AD9280、STM32F407ZGT6 与接线下 L3

## 用于哪个决策

当题目频率或采样同步要求超过 STM32 片内 ADC 的可靠范围时，可把 FPGA +
并行 ADC 作为“高速采集窗口前端”，由 STM32 负责命令、CRC、保存、算法、
状态机和 UI。

## 沿用的方法

FPGA 按高速 ADC 时钟采一段数据并冻结；DRDY 通知 STM32；帧带同步字、
版本、类型、序号、长度和 CRC；STM32 校验成功后按序号 ACK，错误包不 ACK；
FPGA 收到正确 ACK 才释放旧包。

## 不沿用的项目参数

不得直接沿用具体引脚、25 MHz、256 点、SPI 速率、ADC 量程或串口编号。
新题必须根据板卡复用、频率下限、吞吐和存储重新预算。

## 关键预算

- 当前 ADC 采样率 25 MSPS，Nyquist 12.5 MHz；
- 256 点时间窗为 10.24 us；
- 当前 SPI 约 656.25 kbit/s，采用停等 ACK，只能传窗口，不能连续搬运
  25 MB/s 原始流。

## 失败记录

- DRDY 使用 CN2-35/K8 时必须拔掉 UART2_RX 跳帽，否则出现间歇坏帧；
- E10/E11 与 AD9708 复用，不能同时承担 SPI；
- 未接 ADC 时全 `FF` 不代表通信坏；
- 低频输入若窗口太短，会显示近似固定码，不能据此否定 ADC；
- CRC 正确只证明数字链，幅度仍需示波器、端接和标定共同确认。

## 新题复验

重新核对原理图和跳帽；计算有效采样率、Nyquist、每周期点数和窗口时长；
先跑固定测试包，再接 ADC 中点/低频/目标最高频；记录示波器输入、串口连续
日志、CRC 错误率、削顶和幅值换算。任何新位流或 Adapter 修改都要重做 L3。

对应纯协议模块为 `DRV-FPGAPKT-001`。它只完成主机 L2 测试，不继承本工程
的 L3。
