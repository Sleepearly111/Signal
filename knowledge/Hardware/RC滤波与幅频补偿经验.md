# RC滤波与幅频补偿经验

来源：

2024C

## 背景

2024C 的 DAC 以 1 Msps 输出 30～40 kHz 波形，需要用模拟低通削弱采样阶梯和高频镜像。实际调试表明，滤波网络既决定频率衰减，也构成 DAC 负载；只按理想传递函数选取元件，不能保证测试端口幅度正确。

## 核心经验

- 单级 RC 低通截止频率为 `fc=1/(2πRC)`。2024C 使用 R=10 kΩ、C=220 pF，单级截止频率约72.3 kHz。
- 两级相同一阶 RC 级联时，可用二阶近似幅频关系 `H(f)=1/[1+(f/fc)²]` 估算幅度。该近似下，30、35、40 kHz 的幅度系数约为0.853、0.810、0.766，即工作频段内衰减随频率升高而增加。
- 截止频率高于信号最高频率并不等于通带无衰减。30～40 kHz 已达到72.3 kHz 截止频率的约0.41～0.55倍，两级网络会产生可见的幅度倾斜。
- R、C不能只按截止频率组合选择。较低 R 和较大 C 即使得到相似 fc，也可能超过 DAC 输出缓冲的电阻或容性负载能力。2024C 从低阻重负载改为10 kΩ、220 pF后，输出幅度明显改善。
- 软件补偿的基本思路是按频率求链路幅度系数 H，再使用 K=1/H 放大数字目标幅度。补偿后必须重新检查 DAC 正负峰值、安全码、AM 包络峰值和后级增益，避免用软件补偿制造削顶。
- 理论补偿只反映理想 RC 模型，适合用于初始估计和发现趋势。它不包含 DAC 输出阻抗、Buffer 带载能力、隔直电容、合路电阻、探头、示波器终端、元件误差和布线寄生。
- 实测标定应固定完整输出链与测量条件，逐频记录参考点和测试端口幅度，再生成带来源条件的补偿表。标定表只能代表当时的板卡、负载、仪器和温度范围；更换链路后需要重新验证。

## 使用条件

- 输出链近似线性、时不变，且幅度误差主要表现为可重复的频率响应。
- 已明确是单级还是多级 RC，以及后级负载对每一级极点的影响。
- 软件端有足够幅度余量执行补偿，不会超过 DAC 或放大器线性范围。
- 实测表记录频率、输入目标、测量点、负载、探头、终端方式和仪器条件。

## 限制

- `H(f)=1/[1+(f/fc)²]` 是两级互不加载、参数相同条件下的近似；级间加载或后级阻抗较低时不再准确。
- 理论11点补偿表不是实测资产，不能据此声称幅度精度已经标定。
- 软件补偿只能修正可重复的幅值误差，不能消除噪声、量化误差、削顶、相位误差、温漂或随机负载变化。
- 2024C 尚未完成全频全幅的定量精度、低电平隔离和AM包络精度验证。
