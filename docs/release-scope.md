# 发布范围与依赖

这次整理把代码、接线和实测说明放在同一项目页。各目录的附加证据见该项目 README，旧工程入口见仓库首页。

- Framework 与 Knowledge 采用原有工程经验、流程文档和经过整理的公开说明。
- Library 提供实验级独立模块、测试与脚手架。按模块核对板级依赖和证据。
- 赛题和厂家手册以官方页面为原文入口。厂商 SDK、工具及预编译库按各自上游许可获取。
- FPGA 队友实现、专有模块原理图、赛场原始记录和个人资料保留在原资料处。项目页公开接口、能核对的接线、可公开的测量统计和实现边界。
- 新增项目代码以可查阅的应用层快照为主。板级复现需要相应的 CubeMX 版本、HAL/CMSIS 依赖、板卡和匹配的 FPGA 固件，必要时还需要串口屏工程。
- 仓库公开提供查阅。授权范围由各文件的作者与现有许可决定，新增资料未套用统一的再分发许可证。
