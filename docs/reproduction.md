# 赛后归档和复现清单

1. 固定版本。记录 MCU 工程提交、CubeMX 配置、编译器、FPGA 工程与实际位流、HMI 版本。
2. 写接线。记录源端、接收端、方向、电平、共地、供电、偏置、端接和接插件。明确哪些来自代码配置，哪些实机核对过。
3. 写采样预算。记录原始速率、通道分配、抗混叠、抽取后速率、窗口长度和 FFT 栅格。
4. 固定测量条件。记录信号源幅值模式、线缆、负载、仪器、预热、采样次数，保留理论值和实测值。
5. 按功能注明证据。L0 为设计或原型，L1 为已构建，L2 为软件测试，L3 为指定实物条件下的验证，L4 为按赛题条件验收。
6. 提取公共模块。确认来源、替换项目依赖、给出独立接口和测试，再记录来源与新模块各自的验证范围。
7. 起板顺序。先确认供电、电平和共地，再依次核对时钟、采集、通信、算法、输出与显示。先测可控单信号，再测组合和边界。
