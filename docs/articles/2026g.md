# 2026 电赛 G 题复盘｜AD9248 + FPGA + STM32F407 怎样用 4096 点测出基波和谐波

如果用 STM32 直接做频谱，第一步很容易变成“挑一颗更快的 MCU”。我们做周期信号测量分析装置时，先算了采样率、FFT 点数和分辨率，然后才决定把哪些任务交给 FPGA。

赛后我把接线、STM32 应用层、15 组台架结果和以往的信号类项目整理到了 [GitHub · Signal](https://github.com/Sleepearly111/Signal)。下面用 2026 G 题的样机说明这套分工。

## 为什么选 2 MSPS 和 4096 点

赛题中的被测成分最高到 500 kHz，频谱间隔要求不大于 500 Hz。最终的 FPGA 输出是 2 MSPS，STM32 每次处理 4096 点。FFT 栅格 `2,000,000 / 4096` 等于 488.28125 Hz，输出 Nyquist 频率是 1 MHz。

原始 ADC 侧用 25 MSPS。FPGA 先做 320 抽头 FIR，再进行 2/25 采样率转换。这样可以在降采样前先削弱带外分量。若信号已经在 ADC 处混叠，后级 FIR 无法从频谱中恢复原来的分量。

## 实际接线与软件分工

信号源通过 50 Ω 同轴线接 AD9248 模块 INA。板载 AD8132 做单端转差分。AD9248 只用 A 通道，经 Cyclone IV FPGA 处理后，通过 SPI3 把窗口传给 STM32F407。

板上的 SPI3 用 PC10、PC11、PC12，PB0 是低有效片选，PD6 接 FPGA DRDY。串口屏走 USART1。线缆标称 50 Ω 和接收端是否真的有 50 Ω 终端要分别核对。信号源显示的电压也会随 50 Ω / High-Z 模式变化。

FPGA 等待窗口分包和确认。STM32 先核对包序、CRC 和采样配置，再用 Hann 窗和 FFT 查找基波与谐波。对题目给定的 500 Hz 频率网格做联合正弦拟合，最后结合标定计算频谱分量、有效值和总峰峰值。多个谐波叠加时，不能直接把各分量 Vpp 相加。用重构波形求最大值、最小值更直接。

## 15 组测试覆盖了什么

三问各测 5 组，每组取 20 个有效窗口的中位数。第三问加入了 200 mVpp、1.0–1.2 MHz 的单频干扰。

| 本轮指标 | 结果 |
| --- | --- |
| 数值与时间门限 | 15/15 组通过 |
| 最大峰峰值误差 | 1.470 mV |
| 最大有效值误差 | 0.428 mV |
| 最大频谱分量幅值误差 | 约 0.51 mVpk |
| 最慢首个有效结果 | 1.547 s |

这些数据对应当时的接线、标定和测试点。屏幕上能否稳定显示完整周期、频谱布局是否清楚，以及更宽频段的干扰表现，需要分别检查。
